Operator requirements

  • A personal laptop able to run modern browsers and, if required, virtualization software
  • Power adapter or charger — outlets are provided on site
  • An updated modern browser; Firefox or Chrome recommended
  • Any workshop-specific software or virtual machines, announced beforehand
  • Network access credentials are provided on site
Training environment is not the competition environment — workshop materials, examples and practice exercises are educational preparation only. They do not reveal actual competition challenges, infrastructure or flags.
