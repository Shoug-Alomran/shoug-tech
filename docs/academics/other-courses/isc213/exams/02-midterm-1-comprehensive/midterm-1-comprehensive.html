    00 How the doctor marks, and how this page marks

    • Definitions: learn them exactly. Some are hidden inside a paragraph (Ijtihad is a footnote, Gharar sits inside an evidence, "collective insurance" is buried in an intro sentence). The model answers highlight the definition words.
    • "List three reasons": literally write 1, 2, 3. One line each, starting with the keyword of the point.
    • Keywords: for every list, remember the keyword of each point: donation vs compensation, profit vs solidarity, personal vs common.
    • Evidence / hadith: give the main hadith or verse repeated in the lecture, then one line on what it proves.
    • Essays: state the ruling first, then the reasons as a numbered list, then the evidence.

    Marking here is keyword-based: the page ticks the keywords it can find in what you typed. Wording varies, so untick anything it credited wrongly and tick anything you wrote in your own words. Your answers are saved in this browser.
