System Modeling with UML

Context, interaction, structural and behavioral models, then UML in detail: use-case diagrams with include/extend/generalization, sequence diagrams and messages, class diagrams with association, aggregation, composition, generalization and multiplicity, activity diagrams with swimlanes, and state machine diagrams.

Slide 81 / 112

Aggregation vs. Composition

Notes

  1. 1

    Aggregation: whole–part where parts can exist alone (Department–Professor). Composition: parts die with the whole (House–Room).

  2. 2

    Memory trick Filled diamond = "dies with" (composition). Hollow diamond = "can live without" (aggregation).
