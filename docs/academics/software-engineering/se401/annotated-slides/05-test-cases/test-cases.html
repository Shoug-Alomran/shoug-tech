                        1. Triangle problem: classify three sides as equilateral, isosceles, scalene, or not a triangle: include invalid inputs (0, negatives, a + b ≤ c).
                        🎯 How this can come up · 1 question
                        Written

                        Give three test cases for a program that classifies a triangle from three integer sides.

                        (3, 3, 3) → equilateral; (3, 3, 4) → isosceles; (3, 4, 5) → scalene; plus invalid ones such as (1, 2, 3) → not a triangle (a + b = c) and (0, 4, 5) or (−1, 2, 2) → invalid input.
