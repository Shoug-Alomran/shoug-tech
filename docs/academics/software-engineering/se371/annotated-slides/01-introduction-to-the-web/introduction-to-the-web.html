Introduction to the Web

A short history of the internet (circuit vs. packet switching), the birth of the web, static vs. dynamic sites and Web 2.0, the client–server model, internet protocols and the layered architecture, IP addresses and ports, DNS and domain names, URLs, HTTP requests, methods and response codes, browsers, web servers and development stacks.

HTTP Request Methods

Notes

  1. 1

    GET: data in the URL query string (bookmarkable, cached, length-limited, visible). POST: data in the request body (forms that change data).

  2. 2

    Trap GET requests should not change data; use POST (or PUT/DELETE) for changes.
