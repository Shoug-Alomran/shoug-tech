Let vs const

Notes

  1. 1

    let: block-scoped, can be reassigned. const: block-scoped, can’t be reassigned (but a const object’s contents CAN change). Avoid var.

  2. 2

    Trap const arr = [1]; arr.push(2) is fine: the binding is constant, not the array.
