Server-Side Node.js and Express

Node.js and JavaScript everywhere, modules (CommonJS and ES imports), core modules and a simple HTTP server, blocking vs. non-blocking architectures, asynchronous code with callbacks, promises, async/await and fetch, npm and package.json, CORS, Express routing and middleware, route parameters vs. query strings vs. forms, and EJS view engines.
