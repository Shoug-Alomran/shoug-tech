Overview

Security Vulnerabilities, Threats and Countermeasures

Vulnerabilities layer by layer: hardware (processors, protection rings, operating and process states), memory protection (MMU, paging, ASLR), storage, I/O, firmware, client and server systems, databases, the cloud (shared responsibility), IoT, web, mobile (BYOD) and OS protection mechanisms. Major 181 and Final 221 B asked about rings, states and emanations.
