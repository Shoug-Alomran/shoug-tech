STRIDE

Notes

  1. 1

    Tip STRIDE → property violated: Spoofing → authentication · Tampering → integrity · Repudiation → non-repudiation · Information disclosure → confidentiality · Denial of service → availability · Elevation of privilege → authorization.

Exam angle

PredictionQ1

For a mobile banking app, give one STRIDE threat example, its violated property and a mitigation for Spoofing, Tampering and Denial of service. (Major C)

Compare with the model answer

Spoofing: an attacker logs in with stolen credentials → authentication → enforce MFA, strong passwords, account lockout. Tampering: a man in the middle changes the amount of a transfer → integrity → TLS for all API traffic, sign/HMAC requests. Denial of service: flooding the transaction API → availability → rate limiting, WAF rules, DDoS protection, load balancing.
