Slide 9 / 38

Introduction

Notes

  1. 1

    Defence in depth: layered safeguards: physical (guards, locks), perimeter (firewalls, border routers, VPN), network (segments, NIDS), host (OS hardening, patching, antivirus), application, data (encryption, ACLs), plus policies and awareness.

  2. 2

    If one layer fails, the others still protect.

  3. 3

    Trap Defence in depth ≠ fail-over. “When one device fails another takes over” is redundancy (availability), not layering.
