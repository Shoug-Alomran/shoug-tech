Authentication and Access Control

Identification, authentication (the three factors, biometrics and their error rates, passwords, one-time passwords) and authorization (access criteria, authorization creep, SSO), the access control models (DAC, MAC, RBAC) and techniques (rule-based, constrained interfaces, matrices), centralized administration (RADIUS, TACACS, Diameter) vs. decentralized, and accountability. Both Final 221 papers had a six-part matching question on these models. (The Slides page lists this PDF under “ICS and SCADA”.)

Slide 17 / 35

SSO : Pros and Cons

Notes

  1. 1

    SSO pros: fewer passwords, convenience. Cons: one compromised credential opens everything (single point of failure).

Exam angle

PredictionQ1

Give one advantage and one disadvantage of SSO.

Compare with the model answer

Advantage: users remember one strong credential and log in once, reducing password fatigue and admin work. Disadvantage: if that one credential (or the authentication server) is compromised, the attacker gets access to every system.
