Symmetric Cryptosystem Characteristics

Notes

  1. 1

    Symmetric needs: efficient E and D, and the ciphertext must be hard to invert without the key. Problem: secure key distribution.

Exam angle

Past exam · Major 181

MCQ · problem with symmetric encryption = key distribution

Past exam · Major C

D · why symmetric is preferred for bulk data

Past exam · Major 181Q1

The classic problem with symmetric encryption is:

  1. Work factor ignores key size
  2. Secure distribution of the secret key
  3. It is slower than asymmetric
  4. Algorithms are proprietary
Show answer

B. Secure distribution of the secret key — Major 181.

PredictionQ2

Why is symmetric encryption preferred for large amounts of data? (Major C)

Show answer

It uses one shared key and simple, fast operations (substitution, permutation, XOR), so it is far faster and lighter than asymmetric algorithms, which do heavy maths on huge numbers. Asymmetric is used only to exchange the symmetric key or to sign (hybrid encryption).

Substitution Ciphers: Hill Cipher

Notes

  1. 1

    Hill (1929): m letters at a time as a vector, multiplied by an m × m key matrix mod 26.

Exam angle

Past exam · Major A

C · Hill encrypt HELP

Past exam · Major C

B · Hill key suitability and decryption

PredictionQ1

Encrypt HE with a Hill key K = [[3, 3], [2, 5]] using the row approach. (Major A)

Show answer

HE = (7, 4). (7, 4) × K = (7·3 + 4·2, 7·3 + 4·5) = (29, 41) mod 26 = (3, 15) → DP.

PredictionQ2

Any 2 × 2 matrix can be used as a Hill cipher key.

Show answer

False — Its determinant must have an inverse mod 26 (coprime with 26).

Slide 51 / 68

Padding

Notes

  1. 1

    Count characters as bytes; blocks = ceil(bytes / (b/8)); padding = blocks × (b/8) − bytes.

Exam angle

Past exam · Major A

D · blocks and padding for “Incomprehensibilities”

Past exam · Major B

blocks and padding, b = 64

PredictionQ1

b = 128 bits. Plaintext “Incomprehensibilities”. How many blocks and how many padded bits? (Major A)

Show answer

21 characters = 21 bytes. A block holds 16 bytes → 2 blocks (32 bytes). Padding = 32 − 21 = 11 bytes = 88 bits.

Past exam · Major BQ2

b = 64 bits, plaintext of 29 bytes. How many blocks?

  1. 29
  2. 5
  3. 3
  4. 4
Show answer

D. 4 — Major B: 8 bytes per block → 4 blocks, 3 bytes (24 bits) of padding.

Slide 56 / 68

Block Cipher Modes

Notes

  1. 1

    A mode describes how a block cipher handles a sequence of blocks. ECB: each block alone (identical blocks → identical ciphertext).

  2. 2

    Tip Modes: ECB C=E(P) · CBC C[i]=E(P[i] ⊕ C[i−1]), C[−1]=IV · CFB C[i]=E(C[i−1]) ⊕ P[i] · OFB keystream V[i]=E(V[i−1]) · CTR keystream E(counter).

Slide 57 / 68

Cipher Block Chaining (CBC) Mode

Notes

  1. 1

    CBC: XOR each plaintext block with the previous ciphertext block (IV first), then encrypt. Decrypt: P[i] = D_K(C[i]) ⊕ C[i−1].

Exam angle

PredictionQ1

In CBC, write the decryption function for P[2]. (Major A)

Show answer

P[2] = D_K(C[2]) ⊕ C[1] (with C[−1] = IV for the first block).

PredictionQ2

Which mode XORs each plaintext block with the previous ciphertext block before encryption?

  1. CBC
  2. OFB
  3. CTR
  4. ECB
Show answer

A. CBC

Slide 58 / 68

Cipher Feedback (CFB) Mode

Notes

  1. 1

    CFB: encrypt the previous ciphertext block, then XOR with the plaintext: C[i] = E_K(C[i−1]) ⊕ P[i].

Slide 59 / 68

Output Feedback (OFB) Mode

Notes
