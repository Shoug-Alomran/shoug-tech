ICS/SCADA System Security

Cyber-physical systems and industrial control: IT vs. OT, the Purdue model, the ICS/SCADA architecture (control center, HMI, MTU, PLCs and RTUs, communication network, field instruments), SCADA protocols, vulnerabilities, threats, the security objectives (availability first), security requirements, policies, and governance.
