I. Choose the best answer/choice for the below statements:(   /1 marks)
1.

What is layer 4 of the OSI model?

Counting up from the bottom: 1 Physical, 2 Data Link, 3 Network, 4 Transport, 5 Session, 6 Presentation, 7 Application.
2.

What is a TCP wrapper?

A TCP wrapper sits in front of network services and allows or denies connections by user or system ID, which makes it a basic host firewall.
3.

Which of the following is NOT true regarding firewalls?

Firewalls filter traffic by rules; they log, raise alarms and cannot stop insiders. Spotting viruses inside the content is antivirus work.
2
4.

What is encapsulation?

Each layer wraps the data from the layer above with its own header (and the data link layer a footer) on the way down.
5.

Which one of the following devices is most susceptible to TEMPEST monitoring of its emanations?

TEMPEST is about reading electromagnetic emanations. Monitors give off the strongest readable signal of these devices.
6.

Which one of the following security modes does not require that all users have a security clearance for the highest level of information processed by the system?

Dedicated, system-high and compartmented modes all require clearance for the highest level. Multilevel mode lets users with lower clearances work while the system enforces separation.
7.

Which of the following is a problem with symmetric key encryption?

Both sides need the same secret, so getting it to them securely is the classic problem. Symmetric encryption is faster than asymmetric, not slower.
8.

In public key cryptography

The two keys are a pair: whatever one encrypts only the other decrypts. Both directions are used (encryption with the public key, signatures with the private key), so the 'only' in (a) and (b) is wrong.
9.

In a block cipher, diffusion

Diffusion spreads each plaintext bit over many ciphertext bits. Concealing the relationship (a) is confusion, which S-boxes (c) provide.
3
10.

What is used to create a digital signature?

The sender encrypts the message digest with their own private key; anyone verifies it with the sender's public key.
11.

Why would a certificate authority revoke a certificate?

A compromised private key means someone else can sign as the user, so the CA puts the certificate on its revocation list. A public key is public by design.
12.

Which of the following best describes a certificate authority?

A CA is the trusted third party that issues certificates binding an identity to a public key.
II. State whether these statements are True or False:(   /0,5 marks)
1.

CROSS-SITE SCRIPTING (XSS) is a form of malicious code-injection attack in which an attacker is able to compromise a web server.

Keyed TRUE on the instructor's answer sheet: XSS injects malicious script through a vulnerable web application.
2.

Defense in depth is used to provide a protective multilayer barrier against various forms of attack.

Layered, independent controls are the definition of defense in depth.
3.

Wired Equivalent Privacy (WEP) uses a predefined shared secret key.

WEP uses a static pre-shared key configured on the access point and every client.

In Symmetric multiprocessing (SMP) the processors are often operating independently of each other.

FALSE. In SMP the processors share the OS and memory and work together. The instructor cites the CISSP book (p. 495): it is asymmetric multiprocessing (AMP) where processors often operate independently.

1. Shortly describe the Authoritative Name Server (definition and types).(   /2 marks)
Model answer · 2 marks

An Authoritative Name Server holds the actual DNS records for a particular domain / address.

There are two types of Authoritative Name Servers:

  • Primary authoritative name server hosts the original zone file for the domain.
  • Secondary authoritative name servers can be used to host read-only copies of the zone file.
2. Shortly describe the Grid Computing.(   /2 marks)
Model answer · 2 marks
  • Grid computing is a form of parallel distributed processing that loosely groups a significant number of processing nodes to work toward a specific processing goal.
  • The biggest security concern with grid computing is that the content of each work packet is potentially exposed to the world.
  • Grid computing often uses a central primary core of servers to manage the project, track work packets, and integrate returned work segments.
  • If the central servers are overloaded or go offline, complete failure or crashing of the grid can occur.

Model answer · 2 marks
  • Infrastructure mode — wireless NICs on systems can’t interact directly, and the restrictions of the wireless access point for wireless network access are enforced.
