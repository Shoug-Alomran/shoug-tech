Q1: Choose the best option: [0.5 Mark Each = 1 Marks]

1.

Which of the following is not a physical security measure to protect against physical hacking?

Patching software is a technical control; it does nothing against someone who walks up to the machine. A phishing policy (a) is also not physical (it is administrative), so the question has two defensible answers; (b) is keyed, matching the same question on the Semester 222 quiz.
2.

What is a characteristic of a layered defense-in-depth security approach?

Defense in depth stacks independent safeguards, so losing one leaves the others working. (d) describes fail-over redundancy, which protects availability, not layering.
