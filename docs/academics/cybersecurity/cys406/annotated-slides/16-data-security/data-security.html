                                                          1. Full: everything (slow backup, fast restore). Incremental: changes since the LAST backup (fast backup, slow restore: full + every incremental). Differential: changes since the last FULL (restore = full + latest differential).
                                                          🎯 How this can come up · 2 questions
                                                          MCQ

                                                          Restoring from full + differential backups needs:

                                                          Correct: The last full and the latest differential.

                                                          MCQ

                                                          Which backup type is fastest to perform each day?

                                                          Correct: Incremental.
