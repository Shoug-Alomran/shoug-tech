Slide 2 / 25

Honeypot

Notes

  1. 1

    Honeypot: a decoy system with no production value; any interaction with it is suspicious. Used to detect and study attackers.

Exam angle

PredictionQ1

The purpose of a honeypot is to:

  1. Lure attackers so they can be detected and studied
  2. Speed up the network
  3. Encrypt traffic
  4. Replace the firewall
Show answer

A. Lure attackers so they can be detected and studied

Slide 3 / 25

Types of Honeypots

Notes

  1. 1

    Low-interaction: emulates a few services (safe, limited data). High-interaction: real OS and services (rich data, more risk). Production vs. research honeypots.

Exam angle

PredictionQ1

Which honeypot gives the most information but carries the most risk?

  1. Passive
  2. Low-interaction
  3. Medium-interaction
  4. High-interaction
Show answer

D. High-interaction

SOCKS Proxy

Notes

Slide 17 / 25

Anonymous Proxy

Notes

  1. 1

    Anonymous proxy hides the client’s IP from the server.

Slide 18 / 25

Reverse Proxy

Notes

  1. 1

    Reverse proxy: sits in front of SERVERS (load balancing, TLS termination, protection).

  2. 2

    Trap Forward proxy protects/represents clients; reverse proxy protects/represents servers.

Exam angle

PredictionQ1

A proxy that receives requests on behalf of a company’s web servers is a:

  1. Anonymous proxy
  2. SOCKS proxy
  3. Transparent proxy
  4. Reverse proxy
Show answer

D. Reverse proxy
