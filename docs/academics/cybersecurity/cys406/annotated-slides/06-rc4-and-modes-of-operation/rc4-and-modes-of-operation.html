                3. RC4

                a proprietary cipher owned by RSA DSI

                • another Ron Rivest design, simple but effective
                • variable key size, byte-oriented stream cipher
                • widely used (web SSL/TLS, wireless WEP/WPA)
                • key forms random permutation of all 8-bit values
                • uses that permutation to scramble input info
                • processed a byte at a time

                                  Modes of Operation

                                  block ciphers encrypt fixed size blocks

                                  • eg. DES encrypts 64-bit blocks with 56-bit key need some way to en/decrypt arbitrary amounts of data in practise e.g. a message of 1000 bytes ⚫

                                  NIST SP 800-38A defines 5 modes have block and stream modes to cover a wide variety of applications can be used with any block cipher

                                  21
                                  Exam weight ●○○ Low

                                    Message Padding

                                    at end of message must handle a possible last short block

                                    • which is not as large as blocksize of cipher
                                    • pad either with known non-data value (eg nulls)
                                    • or pad last block along with count of pad size
                                      • eg. [ b1 b2 b3 0 0 0 0 5]
                                      • means have 3 data bytes, then 5 bytes pad+count
                                    • this may require an extra entire block over those in message there are other modes, which avoid the need for an extra block

                                            Advantages and Limitations of CBC

                                            a ciphertext block depends on all blocks before it any change to a block affects all following ciphertext blocks need Initialization Vector (IV)

                                            • which must be known to sender & receiver
                                            • if sent in clear, attacker can change bits of first block, and change IV to compensate
                                            • hence IV must either be a fixed value
                                            • (as in EFTPOS Electronic Funds Transfer at Point Of Sale)
                                            • or must be sent encrypted in ECB mode before rest of message
