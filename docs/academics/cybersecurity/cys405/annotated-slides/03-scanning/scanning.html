                                MCQ

                                Which scan completes the full three-way handshake?

                                Correct: TCP connect scan.

                                Exam weight ●●● High
                                1. Stealth / half-open (SYN) scan: SYN → SYN/ACK means open → send RST instead of ACK. Less likely to be logged. nmap -sS.
                                🎯 How this can come up · 2 questions
                                MCQ

                                In a SYN scan, an open port replies with:

                                Correct: SYN/ACK.

                                MCQ

                                Nmap option for a SYN (stealth) scan:

                                Correct: -sS.

                                Exam weight ●○○ Low
                                1. Inverse TCP flag scans (FIN, NULL, URG/PSH): no response = open (or filtered); RST = closed. Do not work against Windows.
                                Exam weight ●●● High
                                1. Xmas scan: FIN + URG + PSH set ("lit up like a Christmas tree"). No reply → open; RST → closed.
                                Exam trapIn SYN scans a reply means OPEN; in Xmas/FIN/NULL scans NO reply means open.
                                🎯 How this can come up · 1 question
                                MCQ

                                An Xmas scan sets which flags?

                                Correct: FIN, URG, PSH.

                                Exam weight ●○○ Low
                                1. ACK scan: maps firewall rules (filtered vs. unfiltered), not open ports.
                                Exam weight ●○○ Low
                                  Exam weight ●●● High
                                  1. Idle (zombie) scan: uses a third host’s predictable IP ID to scan without revealing your address.

                                                          Analyzing the Results

                                                          1. Analyze the services that have been revealed.
                                                          2. Explore vulnerabilities for each service or system.
                                                          3. Research and locate any potential exploits that can be used to attack the system.

                                                          The attacker can use a search engine to gather information about potential attacks by searching the OS and exploits.
