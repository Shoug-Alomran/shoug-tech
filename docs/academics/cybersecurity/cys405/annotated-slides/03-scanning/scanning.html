Slide 22 / 43

Inverse TCP Flag Scanning

Notes

  1. 1

    Inverse TCP flag scans (FIN, NULL, URG/PSH): no response = open (or filtered); RST = closed. Do not work against Windows.

Slide 23 / 43

Xmas Scan

Notes

  1. 1

    Xmas scan: FIN + URG + PSH set ("lit up like a Christmas tree"). No reply → open; RST → closed.

  2. 2

    Trap In SYN scans a reply means OPEN; in Xmas/FIN/NULL scans NO reply means open.

Exam angle
