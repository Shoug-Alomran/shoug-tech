The Relational Model and DBMS Architecture

DBMS languages (DDL, DML, DCL, TCL), relations, tuples, attributes and domains, characteristics of relations, domain, key, NULL, entity-integrity and referential-integrity constraints, update operations and their violations, DBMS modules, and centralized, two-tier and three-tier architectures.

KEY CONSTRAINTS (CONTINUED)

Notes

REFERENTIAL INTEGRITY

Notes

  1. 1

    Referential integrity: a foreign key value must match an existing primary key in the referenced relation, or be NULL.

UPDATE OPERATIONS ON RELATIONS

Notes

  1. 1

    Insert, delete, update can violate constraints. Insert: domain, key, entity, referential. Delete: only referential.

Exam angle

  1. Key constraint
  2. Referential integrity
  3. Entity integrity
  4. Domain constraint
Show answer

B. Referential integrity
