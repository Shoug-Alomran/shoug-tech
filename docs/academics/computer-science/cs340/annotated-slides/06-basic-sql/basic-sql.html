Basic SQL

SQL as a declarative language, SELECT–FROM–WHERE with projection and selection, duplicates and DISTINCT, renaming, LIKE patterns, arithmetic, BETWEEN, ORDER BY, the set operators UNION / INTERSECT / EXCEPT, and INSERT, DELETE and UPDATE.
