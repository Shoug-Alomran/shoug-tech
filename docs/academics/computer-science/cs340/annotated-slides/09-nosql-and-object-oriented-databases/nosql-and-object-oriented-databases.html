      RELATIONAL DATABASES

       The purpose of relational databases is the storage and

      retrieval of highly structured data used mainly in an organization.

       Relational model has persisted (with changes) since the

      1970s.

       A relational database typically stores structured data in

      tables (relations) containing specific data and types of data.

       Relational databases use Structured Query Language

      (SQL).

                                            UPDATE OPERATIONS

                                            With replaceOne you can only replace the entire document, while updateOne allows for updating fields.

                                            Since replaceOne replaces the entire document - fields in the old document not contained in the new will be lost.

                                            With updateOne new fields can be added without losing the fields in the old document.
