NULL VALUES

Notes

  1. 1

    NULL = unknown, unavailable or not applicable. Test with IS NULL / IS NOT NULL, never = NULL.

  2. 2

    Trap WHERE x = NULL is never true; write WHERE x IS NULL.

Exam angle

PredictionQ1

Which finds employees with no supervisor?

  1. WHERE Super_ssn IS NULL
  2. WHERE Super_ssn == NULL
  3. WHERE Super_ssn = 0
  4. WHERE Super_ssn = NULL
Show answer

A. WHERE Super_ssn IS NULL

EXISTS AND UNIQUE

Notes

  1. 1

    EXISTS (subquery) is TRUE if it returns at least one row; NOT EXISTS if it returns none.

Exam angle

Past exam · Final exam 251 (practice replica)

borrowers who never borrowed / orders without a Mouse

PredictionQ1

Find employees who have no dependents.

Show answer

SELECT Fname, Lname FROM EMPLOYEE E WHERE NOT EXISTS (SELECT * FROM DEPENDENT D WHERE D.Essn = E.Ssn);

Slide 53 / 64

old

Notes

  1. 1

    HAVING filters GROUPS (after grouping); WHERE filters ROWS (before grouping).

  2. 2

    Memory trick Condition on an aggregate (SUM, COUNT…) → HAVING.

Exam angle

Past exam · Midterm exam

Q15: customers whose orders total over $500

PredictionQ1

Departments with more than 5 employees:

  1. WHERE COUNT(*) > 5 GROUP BY Dno
  2. HAVING Dno > 5
  3. GROUP BY Dno HAVING COUNT(*) > 5
  4. GROUP BY Dno WHERE COUNT(*) > 5
Show answer

C. GROUP BY Dno HAVING COUNT(*) > 5
