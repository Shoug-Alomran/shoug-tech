BAYES ERROR RATE

Notes

  1. 1

    Overlapping classes mean some inputs could belong to either class. That leftover error is the Bayes error rate.

Exam angle

PredictionQ1

Why can even the optimal classifier not reach zero error?

  3. That remaining error is the Bayes error rate.

PredictionQ2

Explain the Bayes error rate.

Compare with the model answer

It is the smallest possible expected loss under zero-one loss, P(Y != g*(X)). It is irreducible because classes overlap, so even the optimal classifier makes mistakes.

Why can accuracy be misleading? Use an example.

With imbalanced classes or unequal error costs, accuracy can stay high while important mistakes happen. A 99.55% accurate facility guard still admitted 50 intruders, which precision reveals.
