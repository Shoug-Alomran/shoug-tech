PredictionQ3

Explain what a p-value of 0.03 means at alpha = 0.05.

Compare with the model answer

If H0 were true, there would be a 3% chance of a result at least this extreme. Since 0.03 is below 0.05, we reject H0.

Fold differences have mean 0.03 and standard deviation 0.01 over n = 25 folds. Compute t and df.

Compare with the model answer

Slide 14 / 15

Type I and Type II Errors

Notes

  1. 1

    Memory trick Type I cries wolf when there is no wolf. Type II misses the wolf that is there.

Exam angle

PredictionQ1

A medical test tells a healthy person they have a disease. This is:

  1. A false alarm.

PredictionQ2

Which change directly reduces Type II errors?

  1. Lowering alpha reduces Type I errors.

PredictionQ3

Define Type I and Type II errors with a medical example of each.

Compare with the model answer

Type I is rejecting a true H0, a false positive: a healthy person is told they are ill. Type II is failing to reject a false H0, a false negative: a real disease is missed.
