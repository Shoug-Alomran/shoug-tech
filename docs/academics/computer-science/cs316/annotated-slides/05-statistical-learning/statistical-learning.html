Notes

Exam angle

PredictionQ1

Why does prediction error remain even if we knew f exactly?

  3. That spread is the irreducible error.

PredictionQ2

State the reducible and irreducible parts of expected squared error and how each can be changed.

Compare with the model answer

The reducible part is the squared gap between the estimate and f; a better model lowers it. The irreducible part is Var(error), which comes from randomness and no model can remove.

Slide 21 / 30

Error / Loss / Risk

Notes

  1. 1

    Memorize this table. What changes along it is the amount of aggregation: none, then sample average, then expectation over the true distribution.

Exam angle

PredictionQ1

Which term is an expectation over the true distribution?

  3. Training loss is a sample average; loss and error apply to one point.

PredictionQ2

Distinguish error, loss, training loss and risk.

Compare with the model answer

Error is a general distance between a true value and its approximation. Loss is a specific function for one prediction. Training or test loss is the sample average of the loss. Risk is the expected loss over the true distribution.

Slide 23 / 30

Overfitting

Notes

  1. 1

    If any function is allowed, one that memorizes the training data has zero loss and generalizes badly. The slide's conclusion: minimizing training loss is not the ultimate goal.

Exam angle

PredictionQ1

A model has zero training loss but poor predictions on new data. This is:

  2. Poor generalization despite minimal training loss.

PredictionQ2

Explain why minimizing training loss is not the ultimate goal.

Compare with the model answer

A function can match every training pair and reach zero loss but predict new data poorly. The goal is low generalization risk on unseen data.
