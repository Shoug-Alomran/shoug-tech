Pandas for Data Analytics

The two Pandas data structures, Series and DataFrame: how to create them, select with loc and iloc, filter with conditions, read CSV, Excel, SQL and JSON, export to the same formats, and handle file paths and URLs.

Slide 21 / 61

Accessing Data in a DataFrame

Notes

  1. 1

    One pair of brackets returns a Series. Two pairs return a DataFrame, because the inner pair is a list of columns.

Exam angle

PredictionQ1

What does df[["Name", "Age"]] return?

  3. A list of columns returns a DataFrame.

PredictionQ2

Write code that selects the Name and Age columns, then explain why two pairs of brackets are needed.

Compare with the model answer

df[["Name", "Age"]]. The inner brackets are a Python list of column names; the outer ones index the DataFrame, and the result is a DataFrame.

DataFrames: Indexing and Selection

Slide 23 / 61

Label-based Indexing with loc

Notes

  1. 1

    loc reads as "by label or condition": df.loc[df["Age"] > 25] keeps the rows where the condition is True.

Slide 24 / 61

Subsetting with loc

Notes

  1. 1

    In df.loc[:, ["a","b"]], the colon before the comma means all rows, and the list picks the columns.

Slide 25 / 61

Filtering by Multiple Conditions

Notes

  1. 1

    & is AND and | is OR. Each condition needs its own parentheses.

Exam angle

PredictionQ1

Which filter is written correctly?

  1. Use & with parentheses around each condition.

Slide 26 / 61

Integer-based Indexing with iloc

Exam angle

PredictionQ1

What does df.iloc[:3, 1:3] select?

  2. iloc uses integer positions with exclusive ends.

PredictionQ2

Explain the difference between loc and iloc, including how each treats the end of a slice.

Compare with the model answer

loc selects by label or condition and its slice end is inclusive. iloc selects by integer position and its slice end is exclusive.
