Xavier/Glorot Initialization

What is it?

A weight initialization technique that draws from a normal distribution: - Mean (μ) = 0 - Variance (σ²) = 1/n_features

Key Benefits

  • Maintains consistent variance across layers
  • Prevents vanishing/exploding gradients
  • Particularly useful for deep networks and varying feature scales 
import numpy as np

def initialize_parameters(n_features, initialization='xavier'):
    """
    Initializes parameters for linear regression model using Xavier/Glorot initialization.

    Xavier initialization draws weights from a normal distribution with:
    - mean = 0
    - variance = 1/n_features
    This helps maintain the variance of activations and gradients across layers.

    Parameters
    ----------
    n_features : int
        Number of features (or independent variables) in the dataset.
    initialization : str, optional
        Initialization method ('xavier', 'zero'). Default is 'xavier'.

    Returns
    -------
    weights : ndarray
        Initialized weights as a numpy array of shape (n_features,).
    bias : float
        Initialized bias as a scalar.

    Examples
    --------
    >>> weights, bias = initialize_parameters(3)
    >>> print(weights.shape)
    (3,)
    """
    if initialization.lower() == 'xavier':
        # Xavier initialization
        std = np.sqrt(1/n_features)
        weights = None
        # Initialize bias to zero as it doesn't need Xavier initialization
        bias = 0
    elif initialization.lower() == 'zero':
        # Zero initialization
        weights = None
        bias = None
    else:
        raise ValueError("Initialization method must be either 'xavier' or 'zero'")

    return weights, bias

Mean Squared Error (MSE) Formula

The Mean Squared Error for predictions compared to actual values is given by:

$$ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_{\text{pred}}^{(i)} - y^{(i)})^2 $$

Where: - $y_{\text{pred}}^{(i)}$ is the predicted value for the $i$-th sample, calculated as $y_{\text{pred}}^{(i)} = \mathbf{x}^{(i)} \cdot \mathbf{w} + b$. - $y^{(i)}$ is the actual target value for the $i$-th sample. - $n$ is the number of samples. - $\mathbf{x}^{(i)}$ is the feature vector of the $i$-th sample. - $\mathbf{w}$ are the weights. - $b$ is the bias.

Derivation of Gradients

1. Gradient with Respect to Weights ($dW$)

The gradient of MSE with respect to each weight $w_j$ can be computed as:

$$ \frac{\partial \text{MSE}}{\partial w_j} = \frac{\partial}{\partial w_j} \left( \frac{1}{n} \sum_{i=1}^{n} (\mathbf{x}^{(i)} \cdot \mathbf{w} + b - y^{(i)})^2 \right) $$

Using the chain rule, this becomes:

$$ \frac{\partial \text{MSE}}{\partial w_j} = \frac{2}{n} \sum_{i=1}^{n} (\mathbf{x}^{(i)} \cdot \mathbf{w} + b - y^{(i)}) \cdot x_j^{(i)} $$

Summing over all features, we get the gradient vector:

$$ dW = \frac{2}{n} \mathbf{X}^T \cdot (\mathbf{X} \cdot \mathbf{w} + b \cdot \mathbf{1} - \mathbf{y}) $$

However, we usually drop the factor of 2 for simplicity, resulting in:

$$ dW = \frac{1}{n} \mathbf{X}^T \cdot errors $$

Where $errors = \mathbf{X} \cdot \mathbf{w} + b - \mathbf{y}$.

2. Gradient with Respect to Bias ($db$)

Similarly, the gradient of MSE with respect to bias $b$ is:

$$ \frac{\partial \text{MSE}}{\partial b} = \frac{2}{n} \sum_{i=1}^{n} (\mathbf{x}^{(i)} \cdot \mathbf{w} + b - y^{(i)}) $$

Again, dropping the factor of 2 for simplicity:

$$ db = \frac{1}{n} \sum (\mathbf{X} \cdot \mathbf{w} + b - \mathbf{y}) $$

This concludes the derivation of how gradients for weights and bias are calculated in linear regression using MSE, essential for the gradient descent algorithm updates.
