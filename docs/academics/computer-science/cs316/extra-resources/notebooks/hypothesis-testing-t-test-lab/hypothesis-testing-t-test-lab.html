Hands-on with the t-test: one-sample, independent two-sample, and paired

In this notebook you will apply the three classic t-tests to concrete examples, first by hand (with the formulas) and then with scipy, and learn how to choose the right one.

Learning objectives 1. State the hypotheses for each test and compute the t-statistic, degrees of freedom and p-value. 2. Check the assumptions (normality, equal variances) with plots and formal tests. 3. Interpret the result with a confidence interval and an effect size, not only a p-value.

0. Setup

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

plt.rcParams["figure.figsize"] = (7, 4)
plt.rcParams["axes.grid"] = True
ALPHA = 0.01   # significance level used throughout - alpha value set to 0.05
def make_sample(n, mean, sd, seed): # Function that generates data - this requires data is normally distribution (bell shaped) to perform t-test
    """Generate a bell-shaped sample whose mean and standard deviation match
    the requested values exactly (so the results match the textbook example)."""
    rng = np.random.default_rng(seed)
    x = rng.normal(size=n)
    x = (x - x.mean()) / x.std(ddof=1)
    return mean + sd * x

The three tests at a glance

Test Question Data df scipy function
One-sample Is the mean equal to a known value $\mu_0$? one group $n-1$ ttest_1samp
Independent two-sample Do two separate groups have the same mean? two unrelated groups $n_1+n_2-2$ (pooled) ttest_ind
Paired Did the mean change for the same subjects? two linked measurements $n-1$ ($n$ pairs) ttest_rel

Part 1. One-sample t-test

Scenario: student grades. The program sets a benchmark: the average final grade in an introductory programming course should be 70/100. We take a random sample of 25 students' final grades from this year's course. Does this year's mean grade differ from the benchmark?

$$H_0:\ \mu = 70 \qquad H_1:\ \mu \neq 70$$

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}, \qquad df = n-1$$

we want to check if this generalization is correct

mu0 = 70
grades = make_sample(n=25, mean=74, sd=8, seed=5)

print("First 5 grades:", np.round(grades[:5], 1))
print(f"n = {len(grades)},  mean = {grades.mean():.2f},  sd = {grades.std(ddof=1):.2f}")
First 5 grades: [68.3 63.6 73.3 79.3 85.8]
n = 25,  mean = 74.00,  sd = 8.00

Step 1: look at the data. Always plot before testing. 

fig, ax = plt.subplots()
ax.hist(grades, bins=8, edgecolor="white", alpha=0.8)
ax.axvline(mu0, color="red", linestyle="--", label=f"hypothesized mean = {mu0}")
ax.axvline(grades.mean(), color="black", label=f"sample mean = {grades.mean():.1f}")
ax.set_xlabel("Final grade"); ax.set_ylabel("Number of students")
ax.set_title("Final grades of the sample")
ax.legend(); plt.show()

Step 2: compute the test by hand with the formula. 

n = len(grades)
xbar = grades.mean()
s = grades.std(ddof=1)

se = s / np.sqrt(n)                 # standard error of the mean
t_manual = (xbar - mu0) / se
df = n - 1
p_manual = 2 * stats.t.sf(abs(t_manual), df)      # two-tailed p-value
t_crit = stats.t.ppf(1 - ALPHA/2, df) # /2 distributed on both sides because its a two-tailed test

print(f"standard error = {se:.3f}")
print(f"t = {t_manual:.3f}   df = {df}")
print(f"critical value (alpha={ALPHA}, two-tailed) = +/-{t_crit:.3f}")
print(f"p-value = {p_manual:.4f}")
# if t is greater than critical value then we reject the null hypothesis
# Reject/accept in 3 ways - p-value(<alpha reject), t(>critical value reject), CI (if value assumed is outside range) but not necessarily all of them
standard error = 1.600
t = 2.500   df = 24
critical value (alpha=0.1, two-tailed) = +/-1.711
p-value = 0.0197

Step 3: let scipy do it and check that the numbers agree. 

res = stats.ttest_1samp(grades, popmean=mu0)
print(f"scipy: t = {res.statistic:.3f},  p = {res.pvalue:.4f}")

ci = res.confidence_interval(0.99) # Fails to reject H0- accept null hypothesis since it falls within range?
print(f"99% CI for the true mean: ({ci.low:.2f}, {ci.high:.2f})")
print("Reject H0" if res.pvalue < ALPHA else "Fail to reject H0")
scipy: t = 2.500,  p = 0.0197
99% CI for the true mean: (69.52, 78.48)
Fail to reject H0

Step 4: check the assumptions. The data should be roughly normal (less critical when $n \ge 30$). 

# checks if data is normally distributed to apply the t-test - if points are close to red line it indicates a normal distribution otherwise data is skewed
fig, ax = plt.subplots(figsize=(4.5, 4))
stats.probplot(grades, dist="norm", plot=ax)
ax.set_title("Normal Q-Q plot"); plt.show()

w, p_norm = stats.shapiro(grades)
print(f"Shapiro-Wilk: W = {w:.3f}, p = {p_norm:.3f}  ->",
      "no evidence against normality" if p_norm > ALPHA else "normality is doubtful")
Shapiro-Wilk: W = 0.970, p = 0.649  -> no evidence against normality

Step 5: effect size. A p-value says whether there is a difference; Cohen's $d$ says how big it is (rule of thumb: 0.2 small, 0.5 medium, 0.8 large). 

d = (xbar - mu0) / s
print(f"Cohen's d = {d:.2f}")

Conclusion (in words). The mean grade of this course is significantly different from 70 (the sample mean is about 4 points higher). Write your own sentence below in the same style whenever you finish a test.

Part 2. Independent two-sample t-test (equal variance)

Scenario: impact of a teaching strategy. A lecturer teaches two separate sections of the same course. Section A uses a flipped classroom (videos at home, problem solving in class; $n_1=20$ students) and Section B uses traditional lectures ($n_2=22$ students). Do the mean final grades differ?

$$H_0:\ \mu_1 = \mu_2 \qquad H_1:\ \mu_1 \neq \mu_2$$

$$s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}, \qquad t = \frac{\bar{x}_1 - \bar{x}_2}{s_p\sqrt{1/n_1 + 1/n_2}}, \qquad df = n_1+n_2-2$$ 

group_a = make_sample(n=20, mean=78, sd=8, seed=5)   # flipped classroom
group_b = make_sample(n=22, mean=72, sd=9, seed=5)   # lecture

df_teach = pd.DataFrame({
    "grade": np.concatenate([group_a, group_b]),
    "method": ["Flipped"] * len(group_a) + ["Lecture"] * len(group_b),
})
print(df_teach.groupby("method")["grade"].agg(["count", "mean", "std"]).round(2))
fig, ax = plt.subplots()
ax.boxplot([group_a, group_b], showmeans=True)
ax.set_xticks([1, 2]); ax.set_xticklabels(["Flipped (A)", "Lecture (B)"])
for i, g in enumerate([group_a, group_b], start=1):
    ax.scatter(np.random.default_rng(0).normal(i, 0.04, len(g)), g, alpha=0.5, color="gray")
ax.set_ylabel("Final grade"); ax.set_title("Two independent groups"); plt.show()

Step 1: by hand.

n1, n2 = len(group_a), len(group_b)
m1, m2 = group_a.mean(), group_b.mean()
v1, v2 = group_a.var(ddof=1), group_b.var(ddof=1)

sp2 = ((n1 - 1) * v1 + (n2 - 1) * v2) / (n1 + n2 - 2)    # pooled variance
sp = np.sqrt(sp2)
se = sp * np.sqrt(1/n1 + 1/n2)
t_manual = (m1 - m2) / se
df = n1 + n2 - 2
p_manual = 2 * stats.t.sf(abs(t_manual), df)

print(f"pooled variance = {sp2:.2f},  pooled sd = {sp:.2f}")
print(f"standard error = {se:.3f}")
print(f"t = {t_manual:.3f},  df = {df},  p = {p_manual:.4f}")
print(f"critical value = +/-{stats.t.ppf(1 - ALPHA/2, df):.3f}")

Step 2: with scipy. 

res = stats.ttest_ind(group_a, group_b, equal_var=True)
print(f"scipy: t = {res.statistic:.3f},  p = {res.pvalue:.4f}")

diff = m1 - m2
tcrit = stats.t.ppf(1 - ALPHA/2, df)
print(f"Mean difference = {diff:.2f}")
print(f"95% CI for the difference: ({diff - tcrit*se:.2f}, {diff + tcrit*se:.2f})")

Step 3: check the assumptions. Besides normality in each group, this version needs equal variances. 

print("Normality (Shapiro-Wilk):")
for name, g in [("A", group_a), ("B", group_b)]:
    print(f"  group {name}: p = {stats.shapiro(g).pvalue:.3f}")

lev = stats.levene(group_a, group_b)
print(f"\nLevene test for equal variances: p = {lev.pvalue:.3f}  ->",
      "equal variances plausible" if lev.pvalue > ALPHA else "variances differ, use Welch")
print(f"Ratio of standard deviations = {max(group_a.std(ddof=1), group_b.std(ddof=1)) / min(group_a.std(ddof=1), group_b.std(ddof=1)):.2f}  (rule of thumb: < 2 is fine)")

Step 4: effect size and robustness. If the equal-variance assumption is doubtful, use Welch's t-test (equal_var=False). Here the variances are similar, so both tests agree closely. 

d = (m1 - m2) / sp
print(f"Cohen's d = {d:.2f}")

welch = stats.ttest_ind(group_a, group_b, equal_var=False)
print(f"Pooled t-test: t = {res.statistic:.3f}, p = {res.pvalue:.4f}")
print(f"Welch t-test : t = {welch.statistic:.3f}, p = {welch.pvalue:.4f}")

Part 3. Paired t-test

Scenario: comparing two classifiers. A data-science student wants to know whether a Random Forest (A) is more accurate than a Logistic Regression (B). Both classifiers are evaluated on the same 10 datasets, so every dataset gives one pair of accuracies (the numbers below are illustrative).

The datasets differ a lot in difficulty (some are easy, some are hard), but the real question is whether A beats B on the same dataset. So we analyse the differences $d_i = \text{acc}_{A,i} - \text{acc}_{B,i}$:

$$H_0:\ \mu_d = 0 \qquad H_1:\ \mu_d \neq 0$$

$$t = \frac{\bar{d}}{s_d/\sqrt{n}}, \qquad df = n-1$$

acc_a = np.array([84.2, 91.5, 77.8, 88.9, 70.4, 93.1, 82.6, 79.3, 86.7, 90.2])  # Random Forest
acc_b = np.array([82.0, 90.8, 75.1, 87.2, 69.9, 91.4, 83.0, 76.5, 84.1, 88.9])  # Logistic Regression

clf = pd.DataFrame({"dataset": [f"D{i}" for i in range(1, 11)],
                    "RandomForest (A)": acc_a, "LogisticReg (B)": acc_b})
clf["difference (A-B)"] = (clf["RandomForest (A)"] - clf["LogisticReg (B)"]).round(1)
clf
fig, ax = plt.subplots()
for a, b in zip(acc_a, acc_b):
    ax.plot([0, 1], [b, a], marker="o", color="gray", alpha=0.7)
ax.plot([0, 1], [acc_b.mean(), acc_a.mean()], marker="o", color="red", linewidth=3, label="mean")
ax.set_xticks([0, 1]); ax.set_xticklabels(["Logistic Regression (B)", "Random Forest (A)"])
ax.set_ylabel("Accuracy (%)"); ax.set_title("Each line is one dataset"); ax.legend(); plt.show()

Notice that the lines are almost parallel: datasets are very different from each other (70% to 93%), but A is usually a bit above B on the same dataset.

Step 1: by hand.

d = acc_a - acc_b
n = len(d)
dbar = d.mean()
sd = d.std(ddof=1)
se = sd / np.sqrt(n)
t_manual = dbar / se
df = n - 1
p_manual = 2 * stats.t.sf(abs(t_manual), df)

print(f"mean difference = {dbar:.2f} points,  sd of differences = {sd:.2f}")
print(f"standard error = {se:.3f}")
print(f"t = {t_manual:.3f},  df = {df},  p = {p_manual:.4f}")
print(f"critical value = +/-{stats.t.ppf(1 - ALPHA/2, df):.3f}")

Step 2: with scipy. The paired t-test is exactly a one-sample t-test on the differences, so both calls give the same answer. 

res = stats.ttest_rel(acc_a, acc_b)
res_diff = stats.ttest_1samp(d, popmean=0)
print(f"ttest_rel          : t = {res.statistic:.3f}, p = {res.pvalue:.4f}")
print(f"ttest_1samp(diffs) : t = {res_diff.statistic:.3f}, p = {res_diff.pvalue:.4f}")

ci = res.confidence_interval(0.95)
print(f"95% CI for the mean difference: ({ci.low:.2f}, {ci.high:.2f})")

Step 3: assumptions. For the paired test, it is the differences that should be roughly normal (not the raw accuracies). 

fig, axes = plt.subplots(1, 2, figsize=(9, 3.8))
axes[0].hist(d, bins=6, edgecolor="white"); axes[0].set_title("Differences (A - B)")
stats.probplot(d, dist="norm", plot=axes[1]); axes[1].set_title("Q-Q plot of differences")
plt.tight_layout(); plt.show()

print(f"Shapiro-Wilk on differences: p = {stats.shapiro(d).pvalue:.3f}")
print(f"Cohen's d (paired) = {dbar / sd:.2f}")
