Synthetic Dataset Creation

This script generates a synthetic dataset with known properties, using the make_regression function from sklearn. Below are the details:

Description

  • The dataset simulates a linear regression problem with:
  • A single feature (n_features=1)
  • A customizable level of random noise added to the target variable (noise=20 by default)

Parameters

  1. n_samples (default: 200):
    Defines the number of data points (samples) in the dataset.

  2. noise (default: 20):
    Adds random variability to the target values, simulating real-world imperfections.

  3. random_state=42:
    Ensures reproducibility by fixing the random number generator's seed.

Output

The dataset is returned as a Pandas DataFrame with two columns: 1. feature: The single input feature (X). 2. target: The target variable (y), calculated based on the regression formula with added noise. 

def create_dataset(n_samples=200, noise=20):
    """Create a synthetic dataset with known properties."""
    X, y = make_regression(n_samples=n_samples,
                          n_features=1,
                          noise=noise,
                          random_state=42)

    # Convert to DataFrame for better handling
    df = pd.DataFrame({
        'feature': X.flatten(),
        'target': y
    })
    return df

Cross-Validation Setup and Visualization

This function visualizes the data distribution in training and validation sets across folds in a cross-validation setup.

Function: visualize_fold_distribution

Inputs:

  1. df: DataFrame containing the dataset (feature and target).
  2. kf: KFold object defining the cross-validation splits.

Steps:

  1. Iterates through each fold created by KFold.
  2. Splits the dataset into: - Training set: Used for model learning. - Validation set: Used for performance evaluation.
  3. Visualizes distributions: - Feature: Histogram for the feature column. - Target: Histogram for the target column.

Visualization:

  • Each row corresponds to a fold.
  • Each fold has:
  • Feature Distribution (Blue: Train, Red: Validation).
  • Target Distribution (Blue: Train, Red: Validation). 
# 2. Cross-Validation Setup and Visualization
# =========================================

def visualize_fold_distribution(df, kf):
    """Visualize the distribution of data in each fold."""
    fig, axes = plt.subplots(kf.n_splits, 2, figsize=(15, 4*kf.n_splits))

    for fold, (train_idx, val_idx) in enumerate(kf.split(df)):
        train_data = df.iloc[train_idx]
        val_data = df.iloc[val_idx]

        # Feature distribution
        sns.histplot(data=train_data, x='feature', bins=20, ax=axes[fold, 0],
                    color='blue', alpha=0.5, label='Train')
        sns.histplot(data=val_data, x='feature', bins=20, ax=axes[fold, 0],
                    color='red', alpha=0.5, label='Validation')
        axes[fold, 0].set_title(f'Fold {fold+1}: Feature Distribution')
        axes[fold, 0].legend()

        # Target distribution
        sns.histplot(data=train_data, x='target', bins=20, ax=axes[fold, 1],
                    color='blue', alpha=0.5, label='Train')
        sns.histplot(data=val_data, x='target', bins=20, ax=axes[fold, 1],
                    color='red', alpha=0.5, label='Validation')
        axes[fold, 1].set_title(f'Fold {fold+1}: Target Distribution')
        axes[fold, 1].legend()

    plt.tight_layout()
    plt.show()

Model Training and Evaluation with Cross-Validation

This function performs training and evaluation of a linear regression model using cross-validation.

Function: train_and_evaluate_cv

Inputs:

  1. df: DataFrame containing the dataset (feature and target).
  2. kf: KFold object defining the cross-validation splits.

Steps:

  1. Data Splitting: - Splits the data into training and validation sets for each fold.
  2. Model Training: - Fits a LinearRegression model on the training set.
  3. Model Evaluation: - Computes metrics:
    • MSE (Mean Squared Error): Measures prediction error.
    • R² Score: Measures the model's goodness-of-fit.
  4. Stores Predictions: - Keeps validation predictions for later visualization.

Outputs:

  1. results: DataFrame containing performance metrics for each fold: - Fold number. - Training and validation MSE. - Training and validation R² score.
  2. fold_predictions: List of dictionaries with: - Fold number. - Validation indices. - Validation predictions. 
# 3. Model Training and Evaluation
# ==============================

def train_and_evaluate_cv(df, kf): # data set and number of k folda
    """Train and evaluate model using cross-validation."""
    results = []
    fold_predictions = []

    for fold, (train_idx, val_idx) in enumerate(kf.split(df)): # split into train_idx and val_idx - gives index for each fold/round changes in each iteration
        # Split data
        X_train = df.iloc[train_idx]['feature'].values.reshape(-1, 1)
        y_train = df.iloc[train_idx]['target'].values
        X_val = df.iloc[val_idx]['feature'].values.reshape(-1, 1)
        y_val = df.iloc[val_idx]['target'].values

        # Train model
        model = LinearRegression()
        model.fit(X_train, y_train)

        # Make predictions
        train_pred = model.predict(X_train) # to check / compare error of training and validation dataset - to determine whether an overfit occura e.g. if training set drastically different from validation set
        val_pred = model.predict(X_val)

        # Calculate metrics
        fold_results = {
            'fold': fold + 1,
            'train_mse': mean_squared_error(y_train, train_pred),
            'val_mse': mean_squared_error(y_val, val_pred),
            'train_r2': r2_score(y_train, train_pred),
            'val_r2': r2_score(y_val, val_pred)
        }
        results.append(fold_results)

        # Store predictions for later visualization
        fold_predictions.append({
            'fold': fold + 1,
            'val_idx': val_idx,
            'predictions': val_pred
        })

    return pd.DataFrame(results), fold_predictions

Visualizing Predictions Across Folds

This function visualizes the validation predictions for each fold from the cross-validation process.

Function: visualize_predictions

Inputs:

  1. df: DataFrame containing the dataset (feature and target).
  2. fold_predictions: List of dictionaries with: - Fold number. - Validation indices (val_idx). - Validation predictions (predictions).

Steps:

  1. Scatter Plot: - All data points are plotted in gray for context.
  2. Fold Predictions: - Validation predictions for each fold are plotted in distinct colors, using x markers.

Visualization:

  • Gray Points: Represent the entire dataset.
  • Colored x Markers: Represent validation predictions for each fold, labeled by fold number. 
def visualize_predictions(df, fold_predictions):
    """Visualize predictions for each fold."""
    plt.figure(figsize=(12, 6))

    # Plot all data points
    plt.scatter(df['feature'], df['target'], c='gray',
                alpha=0.5, label='All Data')

    # Plot validation predictions for each fold
    colors = plt.cm.rainbow(np.linspace(0, 1, len(fold_predictions)))
    for pred, color in zip(fold_predictions, colors):
        val_idx = pred['val_idx']
        plt.scatter(df.iloc[val_idx]['feature'],
                   pred['predictions'],
                   c=[color],
                   marker='x',
                   s=100,
                   label=f'Fold {pred["fold"]} Predictions')

    plt.xlabel('Feature')
    plt.ylabel('Target')
    plt.title('Predictions Across All Folds')
    plt.legend()
    plt.show()

KFold Cross-Validation

The KFold class in sklearn is used for cross-validation, splitting the dataset into k subsets (folds). It ensures each fold is used once as a test set while the remaining folds form the training set.

Parameters:

  • n_splits: Number of folds (default: 5).
  • shuffle: Whether to shuffle the data before splitting.
  • random_state: Ensures reproducibility.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import KFold, learning_curve
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score
from sklearn.datasets import make_regression
from sklearn.model_selection import validation_curve
import warnings
warnings.filterwarnings('ignore')

# 1. Data Generation and Basic Setup
# ================================

def create_dataset(n_samples=300, noise=20): # creates synthetic - but we assume that we will be given a dataset
    """Create a synthetic dataset with known properties."""
    X, y = make_regression(n_samples=n_samples,
                          n_features=1,
                          noise=noise,
                          random_state=42)
    return X, y

# 2. Generalization Analysis Functions
# =================================

def compute_learning_curves(X, y, cv):
    """Compute learning curves to show how model performance changes with data size."""
    train_sizes = np.linspace(0.1, 1.0, 10)

    train_sizes, train_scores, val_scores = learning_curve(
        LinearRegression(),
        X, y,
        train_sizes=train_sizes,
        cv=cv,
        scoring='neg_mean_squared_error',
        n_jobs=-1
    )

    # Convert MSE to positive values and compute statistics
    train_scores = -train_scores
    val_scores = -val_scores

    train_mean = train_scores.mean(axis=1)
    train_std = train_scores.std(axis=1)
    val_mean = val_scores.mean(axis=1)
    val_std = val_scores.std(axis=1)

    return train_sizes, train_mean, train_std, val_mean, val_std

def plot_learning_curves(train_sizes, train_mean, train_std, val_mean, val_std):
    """Plot learning curves with error bands."""
    plt.figure(figsize=(10, 6))
    plt.plot(train_sizes, train_mean, label='Training Error', color='blue', marker='o')
    plt.fill_between(train_sizes,
                     train_mean - train_std,
                     train_mean + train_std,
                     alpha=0.1,
                     color='blue')

    plt.plot(train_sizes, val_mean, label='Validation Error', color='red', marker='o')
    plt.fill_between(train_sizes,
                     val_mean - val_std,
                     val_mean + val_std,
                     alpha=0.1,
                     color='red')

    plt.xlabel('Training Set Size')
    plt.ylabel('Mean Squared Error')
    plt.title('Learning Curves: Error vs Training Set Size')
    plt.legend(loc='upper right')
    plt.grid(True)
    plt.show()

def analyze_fold_variance(X, y, cv):
    """Analyze prediction variance across folds."""
    predictions = []
    X_sorted_idx = np.argsort(X.flatten())
    X_sorted = X[X_sorted_idx]

    for train_idx, val_idx in cv.split(X):
        model = LinearRegression()
        model.fit(X[train_idx], y[train_idx])
        pred = model.predict(X_sorted)
        predictions.append(pred)

    predictions = np.array(predictions)
    mean_pred = predictions.mean(axis=0)
    std_pred = predictions.std(axis=0)

    return X_sorted, mean_pred, std_pred, X_sorted_idx

def plot_prediction_variance(X, y, X_sorted, mean_pred, std_pred, X_sorted_idx):
    """Visualize prediction variance across the input space."""
    plt.figure(figsize=(12, 6))

    # Plot original data points
    plt.scatter(X, y, c='gray', alpha=0.5, label='Data points')

    # Plot mean predictions with confidence bands
    plt.plot(X_sorted, mean_pred, 'r-', label='Mean prediction', lw=2)
    plt.fill_between(X_sorted.flatten(),
                     mean_pred - 2*std_pred,
                     mean_pred + 2*std_pred,
                     color='r', alpha=0.2,
                     label='±2σ prediction interval')

    plt.xlabel('Feature')
    plt.ylabel('Target')
    plt.title('Model Predictions with Uncertainty Bands')
    plt.legend()
    plt.grid(True)
    plt.show()

def compute_generalization_metrics(X, y, cv):
    """Compute detailed generalization metrics across folds."""
    train_errors = []
    val_errors = []
    complexity_scores = []  # Using R² as a measure of model complexity

    for train_idx, val_idx in cv.split(X):
        X_train, X_val = X[train_idx], X[val_idx]
        y_train, y_val = y[train_idx], y[val_idx]

        model = LinearRegression()
        model.fit(X_train, y_train)

        # Compute errors
        train_pred = model.predict(X_train)
        val_pred = model.predict(X_val)

        train_mse = mean_squared_error(y_train, train_pred)
        val_mse = mean_squared_error(y_val, val_pred)

        # Store metrics
        train_errors.append(train_mse)
        val_errors.append(val_mse)
        complexity_scores.append(r2_score(y_train, train_pred))

    return pd.DataFrame({
        'Fold': range(1, len(train_errors) + 1),
        'Training_Error': train_errors,
        'Validation_Error': val_errors,
        'Model_Complexity': complexity_scores,
        'Generalization_Gap': np.array(val_errors) - np.array(train_errors)
    })

def plot_error_distributions(metrics_df):
    """Visualize the distribution of errors across folds."""
    fig, axes = plt.subplots(2, 2, figsize=(15, 10))

    # Training vs Validation Error
    axes[0, 0].scatter(metrics_df['Training_Error'],
                      metrics_df['Validation_Error'])
    axes[0, 0].plot([0, max(metrics_df['Validation_Error'])],
                    [0, max(metrics_df['Validation_Error'])],
                    'r--')
    axes[0, 0].set_xlabel('Training Error')
    axes[0, 0].set_ylabel('Validation Error')
    axes[0, 0].set_title('Training vs Validation Error')

    # Generalization Gap
    sns.histplot(data=metrics_df, x='Generalization_Gap', ax=axes[0, 1])
    axes[0, 1].set_title('Distribution of Generalization Gap')

    # Error by Fold
    metrics_df.plot(x='Fold', y=['Training_Error', 'Validation_Error'],
                   ax=axes[1, 0], marker='o')
    axes[1, 0].set_title('Errors by Fold')

    # Complexity vs Generalization Gap
    axes[1, 1].scatter(metrics_df['Model_Complexity'],
                      metrics_df['Generalization_Gap'])
    axes[1, 1].set_xlabel('Model Complexity (R²)')
    axes[1, 1].set_ylabel('Generalization Gap')
    axes[1, 1].set_title('Complexity vs Generalization Gap')

    plt.tight_layout()
    plt.show()

def analyze_generalization():
    """Perform complete generalization analysis."""
    # Create dataset
    print("Generating dataset and performing analysis...")
    X, y = create_dataset()

    # Setup cross-validation
    cv = KFold(n_splits=5, shuffle=True, random_state=42)

    # 1. Learning Curves Analysis
    print("\n1. Computing learning curves...")
    train_sizes, train_mean, train_std, val_mean, val_std = compute_learning_curves(X, y, cv) # statistics ab sets to evaluate the distribution of the validation and testing set too see if theyre too skewed from each other
    plot_learning_curves(train_sizes, train_mean, train_std, val_mean, val_std) # plots the distribution

    # 2. Prediction Variance Analysis
    print("\n2. Analyzing prediction variance...")
    X_sorted, mean_pred, std_pred, X_sorted_idx = analyze_fold_variance(X, y, cv)
    plot_prediction_variance(X, y, X_sorted, mean_pred, std_pred, X_sorted_idx)

    # 3. Detailed Generalization Metrics
    print("\n3. Computing generalization metrics...")
    metrics_df = compute_generalization_metrics(X, y, cv)
    print("\nGeneralization Metrics Summary:")
    print("===============================")
    print(metrics_df.describe())

    # 4. Error Distribution Analysis
    print("\n4. Analyzing error distributions...")
    plot_error_distributions(metrics_df)

    # 5. Summary Statistics
    print("\nKey Findings:")
    print("============")
    print(f"Average Generalization Gap: {metrics_df['Generalization_Gap'].mean():.2f}")
    print(f"Generalization Gap Std: {metrics_df['Generalization_Gap'].std():.2f}")
    print(f"Average Training Error: {metrics_df['Training_Error'].mean():.2f}")
    print(f"Average Validation Error: {metrics_df['Validation_Error'].mean():.2f}")

    return metrics_df

if __name__ == "__main__":
    metrics = analyze_generalization()
