T 1–2

Algorithm analysis and recursion

Big-O, Omega, Theta

  • O(g): f(n) ≤ c·g(n) for n ≥ n₀ (upper bound).
  • Ω(g): lower bound. Θ(g): both.
  • Drop constants and lower-order terms: 3n² + 5n + 2 = O(n²).
  • Count primitive operations; nested loops over n → n².
  • A loop that halves (i = i / 2) → log n.

Recursion

  • Every recursive method needs a base case and progress toward it.
  • Linear recursion (one call), binary recursion (two calls, e.g. Fibonacci), multiple recursion.
  • Recursion depth uses the call stack: too deep → StackOverflowError.
  • Naive Fibonacci is O(2ⁿ); with memoization or a loop O(n).
  • Binary search recursive: T(n) = T(n/2) + O(1) → O(log n).
Tail recursion can be rewritten as a loop; Java does not optimize it for you.
T 3–5

Lists, stacks and queues

Singly linked list

  • Node: element + next. Keep head (and tail) plus size.
  • addFirst: new node points to head, head = new. addLast: tail.next = new, tail = new.
  • removeFirst: head = head.next. removeLast needs the node before tail → O(n).

Doubly and circular lists

  • Doubly: prev + next, header and trailer sentinels; insert between two nodes in O(1).
  • Circular: tail.next = head; keep only tail; rotate() moves the head by one step (round robin).

Stack (LIFO)

push, pop, top/peek, size, isEmpty. Uses: undo, browser back, matching parentheses, expression evaluation, recursion.

Parentheses: push each opener; on a closer pop and check it matches; valid only if the stack is empty at the end.

Queue (FIFO)

enqueue (rear), dequeue (front), first. Circular array: rear = (front + size) mod N. Deque allows both ends.

T 6–8

Sorting

Elementary sorts

  • Selection: find the minimum of the unsorted part, swap it to the front. Always n²/2 compares.
  • Insertion: take the next item, shift larger items right, insert. Fast on nearly sorted input.
  • Bubble: swap adjacent out-of-order pairs; the largest bubbles to the end each pass.

Merge sort

Divide in half, sort each half recursively, merge two sorted halves. T(n) = 2T(n/2) + n → n log n. Needs an auxiliary array; stable.

Quick sort

Pick a pivot, partition so smaller left and larger right, recurse on both sides. Shuffle first to avoid the n² worst case (already sorted input with first-element pivot). In place, not stable.

Heap sort

Build a max-heap (bottom-up, O(n)), then repeatedly swap the root with the last element and sink. O(n log n), in place, not stable.

Trace questions: write the array after each pass (or each partition / merge) on its own line.
T 9–11

Trees, BSTs and AVL trees

Terminology

Root, internal node (has a child), leaf, parent, child, siblings, ancestors, descendants, depth (number of ancestors), height (max depth), subtree.

  • Binary tree: at most 2 children. Proper (full): 0 or 2. Complete: all levels full except the last, filled left to right.
  • A binary tree of height h has at most 2^(h+1) − 1 nodes.

Traversals

  • Preorder: node, left, right.
  • Inorder: left, node, right (gives a BST in sorted order).
  • Postorder: left, right, node (sizes, deleting, expression evaluation).
  • Level order (BFS): with a queue.

BST

Left subtree < key < right subtree.

  • Search / insert: go left or right until found or null.
  • Delete: leaf → remove; one child → splice it up; two children → replace with the inorder successor (min of the right subtree) or predecessor, then delete that node.
Inserting keys in sorted order gives a height-n chain: O(n) operations.

AVL trees

  • Balance factor = h(left) − h(right) ∈ {−1, 0, +1}. Height O(log n).
  • After insert, walk up to the first unbalanced node z; y = its taller child, x = y's taller child.
  • LL → single right rotation · RR → single left · LR → left on y then right on z · RL → right on y then left on z.
Same direction (LL/RR) = single rotation; zig-zag (LR/RL) = double rotation. The middle key of x, y, z becomes the root of the subtree.
T 12–13

Heaps and priority queues

Heap properties

  • Complete binary tree stored in an array.
  • Max-heap: parent ≥ children (min-heap: ≤).
  • 1-based array: children of k are 2k and 2k+1, parent is k/2. (0-based: 2k+1, 2k+2, (k−1)/2.)
  • Height = ⌊log n⌋.

Operations

  • insert: add at the end, swim up while larger than the parent. O(log n).
  • delMax: swap root with last, remove last, sink the root (swap with the larger child). O(log n).
  • Build heap bottom-up: sink from n/2 down to 1. O(n).

Trace example

max-heap insert 5, 3, 8, 1, 9
[5] -> [5,3] -> [5,3,8] swim 8 -> [8,3,5]
-> [8,3,5,1] -> [8,3,5,1,9] swim 9: swap 3 -> [8,9,5,1,3]
                             swap 8 -> [9,8,5,1,3]
delMax: swap 9 and 3 -> [3,8,5,1] sink 3 -> [8,3,5,1]
T 14

Hash tables

Hash function

  • Map a key to an index in [0, M): h(k) = k mod M (M prime). Java: (key.hashCode() & 0x7fffffff) % M.
  • Goals: fast, uniform spread. Equal keys must have equal hash codes.
  • Load factor α = n / M.

Separate chaining

Each slot holds a linked list. Average list length α. Keep α around 5 or less; resize when it grows.

Linear probing

Collision → try i+1, i+2, … (wrap around). Keep α ≤ 1/2. Deletion needs re-inserting the cluster after the hole (or tombstones). Clusters slow it down.

Trace example

M = 7, h(k) = k mod 7, linear probing
insert 10 -> 3, 17 -> 3 taken -> 4, 24 -> 3,4 taken -> 5
insert 5 -> 5 taken -> 6, 14 -> 0
table: [14, -, -, 10, 17, 24, 5]
T 15–16

Undirected and directed graphs

Terms

Vertex, edge, degree (in/out for digraphs), path, cycle, connected component, DAG. Sum of degrees = 2E.

Representations

  • Adjacency matrix: V² space, O(1) edge check.
  • Adjacency lists: V + E space, iterate neighbours fast (used in practice).

DFS

Recursive or stack: go deep, mark visited, backtrack. Finds paths, connected components, cycles. Topological sort = reverse postorder of DFS on a DAG.

BFS

Queue: visit all neighbours first, level by level. Gives shortest paths in edges from the source. O(V + E).

Traces: process neighbours in the order given (often increasing number) and write the visit order and the queue/stack after each step.
