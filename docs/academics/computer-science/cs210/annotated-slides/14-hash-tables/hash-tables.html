PredictionQ1

Two objects with the same hashCode must be equal.

False — Equal objects must have equal hash codes, not the reverse.

Collision resolution: open addressing

Notes

  1. 1

    Open addressing / linear probing: on collision, try the next slot (i + 1) until empty.

Exam angle

PredictionQ1

With linear probing, a key that hashes to a full slot goes to:

  1. The end of the table
  2. The next free slot
  3. The previous slot
  4. A linked list
Show answer

B. The next free slot
