Prefix Averages 2 (Linear)

Notes

Exam angle

PredictionQ1

Why is the second prefix-averages algorithm linear?

Compare with the model answer

It keeps a running total, adding one element per step instead of re-summing all earlier elements, so each of the n steps is constant time: O(n) instead of O(n²).
