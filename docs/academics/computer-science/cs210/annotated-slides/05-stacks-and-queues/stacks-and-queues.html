Parentheses Matching

Notes

  1. 1

    Parentheses matching: push openers, pop and compare on closers; stack empty at the end = balanced.

Exam angle

PredictionQ1

How does a stack check that ( [ { } ] ) is balanced?

Show answer

Scan left to right: push every opening symbol; on a closing symbol pop and check it matches. If a pop finds the stack empty or a mismatch, it’s unbalanced; at the end the stack must be empty.

Notes

  1. 1

Exam angle

PredictionQ1

In a circular array queue of capacity N, the index after r is:

  1. (r + 1) mod N
  2. N − r
  3. r − 1
  4. r + 1
Show answer

A. (r + 1) mod N
