1.2 Networks

  • A network is a set of devices (called nodes) connected by communication links.
    • Node can be host (a computer, printer, cell phone) or networking devices (routers, switches, modem, etc...)
    • Link is a communication pathway that transfer data from one device to another
    • Link can be wired or wireless①
  • Type of network connections
    • Point-to-Point: dedicated link between two devices
    • Multipoint: shared link between more than two devices②
  • Distributed system vs. Computer networks
  • A network must be able to meet a certain number of criteria. The most important of these are:
    • Performance
      • Depends on factors such as:
        • # of users, type of transmission medium, capabilities of Network hardware, Network software efficiency
      • Evaluated by:
        • Throughput (amount of data a user can send)
        • Delay (measured in transit time, and response time)
      • To have good performance, we need more throughput and less delay (contradict each other, because when throughput increases, it means more data arrive to the network, this will increase the delay
    • Reliability
      • Measured by:
        • Frequency of failure
        • Time it takes a link to recover from the failure③
    • Security
      • Protecting data from unauthorized users, and damage, applying security policies for recovery from breaches and data losses
6
Exam weight ●●● High
  1. Node = any device (host or router/switch). Link = the pathway between nodes.
  2. Point-to-point = a dedicated link for two devices; multipoint = one link shared by more than two.
  3. The 3 criteria: performance (throughput + delay), reliability (failure frequency + recovery time) and security.
Exam trapMore throughput and less delay pull against each other: pushing more data in raises the delay.
Memory trickCriteria = “PRS”: Performance, Reliability, Security.

Data flow (direction of data flowing in the link) (Figure 1.2)

9
Exam weight ●●● High
  1. Simplex: one direction only, always (keyboard → computer, TV, radio).
  2. Half-duplex: both directions, but one at a time; each side gets the whole channel while sending (walkie-talkie).

Explain the difference between half-duplex and full-duplex, with a real example of each.

Half-duplex: both sides can send but not at the same time, so they take turns and the sender uses the whole channel (walkie-talkie). Full-duplex: both send and receive at the same time and the capacity is split between the two directions (telephone call).

Fully connected mesh topology (for five devices) (Figure 1.8)

  • Dedicated point-to-point link to every other node
  • Number of links = N(N-1)/2①
  • Advantages
    • Dedicated links 🡺 secure, no traffic problems (no congestion)
    • Robust: if one link fails, the network will still work
    • Easy to discover faulty links
  • Disadvantages?
    • Difficult to install & update (too much wiring)
    • Expensive (why?)②
    • Number of Network interface cards (NIC) or Number of I/O ports = (N-1 )per device
    • Number of cables = Number of links
11
Exam weight ●●● High
  1. Every device has a dedicated link to every other one. Links = N(N-1)/2; each device needs N-1 ports (NICs).
  2. Expensive because of all the cabling and ports: that is the answer to “why?”.
Memory trickN = 8 → 8 × 7 / 2 = 28 links, 7 ports per device.
Exam trapPorts per device is N-1, not N(N-1)/2.

Star topology (Figure 1.9)

  • Dedicated point-to-point link to a central controller only①
  • Number of links = N
  • Advantages
    • Less expensive than mesh
    • Easy to install
    • Easy to add and remove devices
    • Robust
    • Easy to discover faulty links
    • Secure but less than mesh
  • Disadvantages?
    • If the central device failed the whole network will not function②
12
Exam weight ●●● High
  1. Each device links only to the central hub/switch, so devices never talk directly.
  2. Single point of failure: the hub. One cable failing only cuts off one device.
Exam trapRobust ≠ fault-proof: one bad link only takes out its device, but the hub failing takes out everything.

Scenario

A 20-employee office wants every computer connected to one central device, easy to manage and to grow. Which topology, and why?

Star. Every PC has its own link to a central switch, so adding or removing a PC is easy, a broken cable only affects one PC, faults are easy to find, and it needs less cabling than a mesh. The switch is the single point of failure.

  • Number of links = 1 Main + N droplines①
  • Advantages
    • Easy to install
    • less cabling than mesh and hub
  • Disadvantages?
    • Difficult to isolate fault
    • Difficult to add new devices
    • A break in the bus cable stops all transmission②
13
Exam weight ●●● High
  1. One long backbone cable; each device hangs off it on a drop line through a tap.
  2. A break in the backbone stops ALL transmission, and faults are hard to isolate.
TipFormulas for N devices: mesh N(N-1)/2 links and N-1 ports each · star N links · ring N links · bus 1 main cable + N drop lines.

1.3 The Internet

  • The Internet is a collection of different networks that run TCP/IP protocols suite①
  • It is made of many wide- and local area networks joined by connecting devices and switching stations
  • In order to be considered on the Internet, your host machine should
    • run TCP/IP protocol
    • have Internet address
    • be able to send Internet Protocol (IP) packets to other machines on the Internet②

Internet Service Providers (ISPs)

  • Backbones: International Service providers ( tier-1 ISPs)
    • International coverage
    • Called Internet backbone networks
    • Few number exists①
    • Own links and routers to connect to other networks:
    • Connected directly to other tier-1 ISPs
    • Examples: Sprint, AT&T, LUMEN, etc.
  • Provider networks: National or regional (
    • Gateways to the international Internet
    • Connected to at least one tier-1 ISPs
    • has a regional or national coverage
    • Example: STC, ITC, Mobily②
  • Local ISPs (Tier-3)
    • Taking services from National Providers③
24
Exam weight ●●● High
  1. Tier 1 = backbones: international, few of them, own their links, connect directly to each other.
  2. Tier 2 = national/regional providers (STC, Mobily); connect to at least one tier-1.
  3. Tier 3 = local ISPs that buy service from the national providers.
Memory trickTier number goes UP as you get closer to the customer: 1 = global, 2 = national, 3 = local.

The Internet today (Figure 1.13)

27
Exam weight ●○○ Low
  1. Backbones in the middle, joined at peering points; provider networks hang off them; customers at the edge.

Methods of ISPs InterConnection

  • Peering is the interconnection of networks, allowing those networks to exchange traffic.①
  • Methods of ISP interconnection (peering):
    • Private Peering Points (Direct Connection)
      • Points at which one ISP is connected to the others and consist of a group of routers (devices that connects networks together)
      • Private Peering Points are owned and operated by ISPs not by a third party telecommunication company
    • Internet Exchange Points (IXP) (Public Peering)
      • is a physical infrastructure through which Internet service providers (ISPs) exchange Internet traffic between their networks
      • A public IXP is managed by a third party and enables any ISP to connect with any other ISP
      • IXP consists of Complex high speed switching networks
      • IXP exchange huge amounts of traffic②
    • Current trend for connecting ISP:
      • International ISPs connect to each other at private peering points
      • National ISPs interconnect using IXP
28
Exam weight ●●● High
  1. Private peering: ISPs connect directly; the points are owned and run by the ISPs themselves.
  2. IXP (public peering): a third party runs a high-speed switching network where any ISP can connect.
  3. Today: international ISPs use private peering; national ISPs meet at IXPs.
Exam trapPrivate peering points are run by the ISPs; an IXP is run by a THIRD party.

1.4 Internet Standards

  • In early 1970s, IBM, Digital Equipment and other vendors developed networking architectures that allow only their own computers to operate in local computer networks
  • Each company network can’t communicate with other company equipments without using a major translation software.①
  • Question: How to allow these different networks communicate with each others easily?
    • Answer: Communicating devices must agree on a protocol or standards
  • Protocol: set of rules controlling the exchange of data between two entities in a system.
    • Entities: application that is capable of sending and receiving information (ex: user applications, email,... etc).
    • Systems: computers, terminals, remote sensors②
30
Exam weight ●●● High
  1. Early vendor networks could not talk to each other without translation software, which is why we need standards.
  2. Protocol = a set of rules controlling data exchange between two entities in a system.
Exam trap“A protocol is the structure or format of the data” ✗. That is only syntax, one element of a protocol.

Internet Standards

  • Standards and protocols specify hardware and software procedures through which computers can correctly and reliably talk to one another
  • Required to allow for interoperability among equipments built by different vendors①
  • Advantages
    • Ensures a large market for equipment and software
    • Provide guidelines to manufacturers, vendors, government agencies.
    • Allows products from different vendors to communicate②

Agreements must be at many levels ...

  • How many volts pulse is a 0 and 1 ?
  • How to determine the end of a message ?
  • How to handle lost messages ?
  • How many bits for different data types ? Integers/Strings, etc.; are ASCII chars ?
  • How machines are identified in a network?
  • How to find the way to reach a machine ?
  • How applications speaks together through the network ?
31
Exam weight ●●○ Medium
  1. Standards = interoperability: gear from different vendors can work together.
  2. Agreements are needed at many levels: voltages for 0/1, message boundaries, lost messages, addressing, routing, applications. Each turns into a layer later.

Written

Why are standards important in data communications? Give examples.

They guarantee interoperability between equipment from different vendors, create a large market for hardware and software, and guide manufacturers and agencies. Examples: Ethernet (IEEE 802.3) lets any NIC talk to any switch; TCP/IP lets any computer join the Internet.

Standards Organizations

  • International Organization for standardization (ISO)
  • International Telecommunication Union (ITU-T) – UN Agency
  • American National Standards Institute (ANSI)
  • Institute of Electrical and Electronic Engineers (IEEE) – specializes in LAN/MAN standards①
  • World Wide Web Consortium (W3)
