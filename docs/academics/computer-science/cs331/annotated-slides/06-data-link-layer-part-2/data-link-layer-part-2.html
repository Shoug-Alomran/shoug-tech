Data Link Layer: Multiple Access Protocols

How many stations share one link: random access (CSMA and its three persistence methods, CSMA/CD), controlled access (reservation, polling, token passing) and channelization (FDMA, TDMA, CDMA). The favourite questions compare them: who is fair, who can collide, and who is stuck at R/M even when alone on the link.

Slide 8 / 34

Random Access – Carrier Sense Multiple Access (CSMA)

Notes

  1. 1

  2. 2

    It reduces collisions but can’t eliminate them: a station far away may not hear a frame that already started.

  3. 3

  4. 4

    Trap “CSMA eliminates collisions” ✗. It only reduces them.

Notes

  1. 1

    Non-persistent: busy → walk away for a random time, then check again.

  2. 2

    Fewer collisions, but the line can sit idle (wasted).

Slide 13 / 34

1-persistent CSMA

Notes

  1. 1

    1-persistent: busy → keep listening → the instant it’s idle, send (probability 1).

  2. 2

    No idle time, but if two stations were waiting, they BOTH send → guaranteed collision.

  3. 3

    Memory trick Non-persistent = polite (walks away). 1-persistent = selfish (stares at the line).

Slide 14 / 34

P-persistent CSMA

Notes

  1. 1

    p-persistent: idle → send with probability p, or wait one slot with probability 1 - p.

  2. 2

    Best of both: fewer collisions (like non-persistent) and less idle time (like 1-persistent).

  3. 3

    Slot = maximum propagation delay.

Exam angle

PredictionQ1

In p-persistent CSMA, a time slot equals:

  1. One bit time
  2. The jam signal time
  3. The maximum propagation delay
  4. The frame time
Show answer

C. The maximum propagation delay

PredictionQ2

Compare non-persistent, 1-persistent and p-persistent CSMA when the channel is busy and when it becomes idle.

Show answer

Non-persistent: if busy, wait a random time then sense again (fewer collisions, wasted idle time). 1-persistent: if busy, keep listening and send immediately with probability 1 when idle (no idle time, collisions guaranteed if several are waiting). p-persistent: keep listening; when idle send with probability p or wait a slot with probability 1 - p (reduces both collisions and idle time).

1-Reservation access method

Notes

  2. 2

    Everyone hears the reservations, so everyone knows the order. Then the reserved data frames follow.

Slide 23 / 34

2- Polling

Notes

  1. 1

    Centralized polling: a PRIMARY controls everything. SELECT = primary wants to send to a secondary. POLL = primary asks a secondary if it has data (data or NAK back).

  2. 2

    Distributed polling: no primary; stations follow a known order and pass the right to send along. Reservation and token passing are distributed polling.

  3. 3

    Memory trick SELect = primary SEnds. POLL = primary coLLects.

Slide 30 / 34

Time-division multiple access (TDMA) (Figure 12.22)

Notes

  1. 1

    Each station has its own time slot on the whole bandwidth.

Slide 31 / 34

Channelization: TDMA

Notes

  1. 1

    TDMA: whole bandwidth, but only in your slot. Still R/M on average even when alone.

  2. 2

    Trap FDMA, TDMA (and controlled access) cap a lone station at R/M; random access lets it use all of R.

Exam angle

PredictionQ1

In TDMA, a station that is the only one with frames can use every time slot.

Show answer

False — It must wait for its own slot.

PredictionQ2

Compare FDMA and TDMA.

Show answer

FDMA divides the channel by frequency: each station gets its own band and sends continuously. TDMA divides it by time: each station uses the whole bandwidth but only in its own slot. Both limit a station to R/M even when it is the only one sending.

Slide 33 / 34

Simple idea of communication with code (Figure 12.23)

Notes

  1. 1

    Each station multiplies its data by its code; the channel carries the SUM; a receiver multiplies by the wanted code to pull its data out.

Slide 34 / 34

FDMA vs. TDMA vs. CDMA

Notes

  1. 1

    FDMA = frequency slices. TDMA = time slices. CDMA = code slices (everyone uses all frequencies all the time).

  2. 2

    Memory trick F = Frequency, T = Time, C = Code.
