Introduction: Protocol Layering, TCP/IP and the OSI Model

Why networks are built in layers, the 7 OSI layers and what each one does, its PDU and its address, how encapsulation wraps data on the way down and unwraps it on the way up, and how the 5-layer TCP/IP suite maps onto OSI. Every later chapter is one of these layers, so this deck is the map for the rest of the course.

Protocol Layers and Service Models

Notes

  1. 1

    Problem: networks are too complex to understand or build as one piece.

  2. 2

    Solution: layers = logical groups of functions. Each layer does one job.

  3. 3

    Layer n-1 serves layer n through an interface (the boundary between two layers).

  4. 4

    Memory trick A layer only talks to the one directly above and below it on the same machine.

Exam angle

  1. Interface
  2. Peer
  3. Header
  4. Protocol
Show answer

A. Interface

PredictionQ2

In a layered architecture, layer n-1 provides a service to layer n.

Show answer

True

Slide 4 / 54

Layers, protocols, and interfaces

Notes

  1. 1

    Horizontal = protocol (layer 3 talks to the other host’s layer 3). Vertical = interface.

  2. 2

    Only layer 1 actually touches the physical medium; everything above is logical communication.

  3. 3

    Trap Protocol ≠ interface. A protocol is between peers on different machines; an interface is between neighbours on the same machine.

Slide 6 / 54

Advantages of Layered Architecture

Notes

  1. 1

    Each layer has its own unique protocols and a well-defined interface → each layer can be built independently.

  2. 2

    So different vendors can build different layers (NIC maker, OS maker, browser maker) and it still works.

Exam angle

PredictionQ1

Give two advantages of a layered network architecture.

Show answer

It breaks a complex process into simpler pieces, so hardware and software are easier to build. And because each layer has its own protocols and a fixed interface, layers can be built independently by different manufacturers, which encourages collaboration and competition.

Slide 13 / 54

OSI model-Basic Operation

Notes

  1. 1

    PDU = data from the layer above (payload) + this layer’s control info.

  2. 2

    Control info goes in a HEADER. Data link is the exception: it adds a header AND a trailer.

  3. 3

    Only the peer layer on the receiver reads that header.

  4. 4

    Trap Only the data link layer adds a trailer (for error detection).

  5. 5

    Seen again Ch 3 Part 1, slide 4: Framing adds the header and trailer

Data Encapsulation

Notes

  1. 1

    Encapsulation: layer N-1 carries layer N’s whole PDU as its data, without looking inside.

  2. 2

    PDU (N-1) = PDU (N) + control info of N-1.

D. Carries layer N’s PDU in its data part without knowing its contents

PredictionQ2

During encapsulation, a lower layer inspects and changes the upper layer’s header.

Show answer

Slide 28 / 54

Data Link Layer

Notes

  1. 1

    Data link PDU = FRAME. Delivery is node-to-node (hop-to-hop) over one link.

  2. 2

    MAC address = physical = hardware = NIC = LAN address. All the same thing.

  3. 3

    The MAC changes at every hop: A’s frame is addressed to the router, not to B.

  4. 4

    Trap Destination MAC = the NEXT HOP, not the final host. Destination IP = the final host.

Slide 32 / 54

Example 1 (Figure 2.8)

Notes

  1. 1

    Same link (a bus), so the frame carries physical addresses 10 → 87 and every station sees it, but only 87 keeps it.

Exam angle

PredictionQ1

On a bus LAN, station 10 sends a frame to station 87. Which stations receive it and which one keeps it?

Show answer

All stations on the bus receive the bits, but each compares the destination physical address with its own. Only 87 matches, so only 87 keeps the frame; the rest drop it.

Slide 33 / 54

Network Layer

Notes

  1. 1

    Network layer PDU = PACKET (datagram). Delivery is source-to-destination (host-to-host) across many networks.

  2. 2

    Logical address = IP address: globally unique.

  3. 3

    Routing: routers choose the best path.

  4. 4

    Memory trick IP = end-to-end destination. MAC = next-hop destination.

  5. 5

    Seen again Ch 7, slide 3: Network-layer duties in depth

Slide 37 / 54

Example 2 (Figure 2.11)

Notes

  1. 1

    The logical (IP) addresses A → P stay the same all the way; the physical addresses are rewritten on each link.

Exam angle

PredictionQ1

A packet travels from host A to host P across two routers. Which addresses change on the way and which stay the same?

Show answer

The logical (IP) source and destination stay A and P end to end. The physical (MAC) source and destination are replaced on every link, because each frame only travels one hop.
