Protocol Layers and Service Models

  • Computer network architecture is complex
    • Too many components
    • How to understand its architecture?
    • How to allow developers and users to deal with this complexity?①
  • Solution 🡺
    • Computer networks functions are designed and implemented as layers
    • Layers are logical groupings of all the processes or functions required for effective data exchange②
    • Layer n-1 provides some service to the layer n through a well-defined interface (boundary between each two layers)
    • Each interface defines what information, operations, and services a layer must provide for the layer above it.③
    • These layers are distributed across all nodes in the network
3
Exam weight ●●○ Medium
  1. Problem: networks are too complex to understand or build as one piece.
  2. Solution: layers = logical groups of functions. Each layer does one job.
  3. Layer n-1 serves layer n through an interface (the boundary between two layers).
Memory trickA layer only talks to the one directly above and below it on the same machine.

Advantages of Layered Architecture

  • Breaks the complicated communication process into layers of simpler processes which allows easier hardware or software implementation①
  • Each layer implements distinct (different from other layers and unique) set of protocols (functions), and
  • Well-defined interface between layers n and n-1
  • The advantage of the above two requirements:
    • The implementation of each layer can be done independently of the other layers.
    • This allows different manufacturers to supply the hardware and software needed to the different layers
      • encourages collaboration & Competition②
6
Exam weight ●●○ Medium
  1. Each layer has its own unique protocols and a well-defined interface → each layer can be built independently.
  2. So different vendors can build different layers (NIC maker, OS maker, browser maker) and it still works.
🎯 How this can come up · 1 question
Written

Give two advantages of a layered network architecture.

It breaks a complex process into simpler pieces, so hardware and software are easier to build. And because each layer has its own protocols and a fixed interface, layers can be built independently by different manufacturers, which encourages collaboration and competition.

Standard Protocol Models

  • The protocols of the various layers are called protocol stack①
  • Two Standard Protocol models (stack) exist:
    • Open System Interconnect (OSI)
    • Transmission Control Protocol/Internet Protocol (TCP/IP)②
7
Exam weight ●○○ Low
  1. Protocol stack = the set of protocols of all the layers.
  2. Two standard stacks: OSI (the reference model) and TCP/IP (what the Internet actually runs).

OSI Model

  • Developed by ISO (the International Organization for Standardization) in the 1970s
  • Provides framework for standardization
  • An open system is a set of protocols that allow any two different systems to communicate regardless of their underlying architecture.
  • Describes how data and network information moves from an application in one computer to an application in another computer.
  • Dominated before 1990①
8
Exam weight ●●○ Medium

Peer-to-Peer Processes

OSI model-Basic Operation

  • Peer-to-Peer communication: Each layer on a sending node communicates (logically) with its peer layer on the receiving node③ using formatted blocks of data called Protocol Data Units (PDU)①
  • PDU = combination of data (payload) from the next higher layer and the control information of the current layer (Specific requests and instructions)
    • Control information are given in the header fields of the block except for the data link (has both header and trailer)②
    • Control information is read and executed ONLY by the peer layer on the receiving node
13
Exam weight ●●● High
  1. PDU = data from the layer above (payload) + this layer’s control info.
  2. Control info goes in a HEADER. Data link is the exception: it adds a header AND a trailer.
  3. Only the peer layer on the receiver reads that header.
Exam trapOnly the data link layer adds a trailer (for error detection).

Physical Layer

  • Deals with the actual communication media
    • Defines the physical characteristics of interfaces and transmission media
      • the way devices are connected to each other and to the link (topology)
      • Shape, size and number of pins of connectors
      • What voltages and currents are used
      • The type of transmission media
      • Transmission mode (duplex type)①
    • Representation of bits – encoding into Electrical or Optical signals
    • Data Rate = transmission rate = bandwidth (number of bits sent per second)②
    • Synchronization of bits (sender and receiver clocks must be synchronized)
    • Devices that operates at this level: Network card, repeater③
26
Exam weight ●●● High
  1. Physical layer defines: interfaces and media, topology, connectors (pins), voltages, transmission mode.
  2. It also handles bit representation (encoding), data rate (bits per second) and bit synchronization.
  3. Devices at layer 1: NIC (its physical part), repeater, hub.

Data Link Layer

  • Data Link layer PDU is called frame
  • Transfers frames across direct connections Node-to-Node (hop-to-hop) delivery①
  • Framing: dividing the stream of bits into units called frames
  • Physical Addressing: sender and receiver physical addresses (Local address – hardware address – NIC address – LAN address)②
  • Physical address = MAC address = hardware/NIC address
  • MAC tells us WHICH DEVICE should receive this frame on the current link.

A ───── Router ───── B: the frame from A carries Destination MAC = Router③

Exam weight ●●● High

  2. MAC address = physical = hardware = NIC = LAN address. All the same thing.
  3. The MAC changes at every hop: A’s frame is addressed to the router, not to B.

🎯 How this can come up · 1 question
Scenario

On a bus LAN, station 10 sends a frame to station 87. Which stations receive it and which one keeps it?

All stations on the bus receive the bits, but each compares the destination physical address with its own. Only 87 matches, so only 87 keeps the frame; the rest drop it.

Network Layer

  • Network Layer PDU is called Packet or Datagram
  • Source-to-destination (host-to-host) delivery of a PACKET possible across MULTIPLE networks.①
  • Logical addressing (Network address)
    • A unique global address that distinguishes each host connected to the Internet
    • In the Internet it is called IP address②
  • Routing
    • Network connecting devices (routers) route or switch the packets to their final destination through the best path③
  • IP address = end-to-end destination MAC address = next-hop destination
33
Exam weight ●●● High
  1. Network layer PDU = PACKET (datagram). Delivery is source-to-destination (host-to-host) across many networks.
  2. Logical address = IP address: globally unique.
  3. Routing: routers choose the best path.
Memory trickIP = end-to-end destination. MAC = next-hop destination.

🎯 How this can come up · 1 question
Written

A packet travels from host A to host P across two routers. Which addresses change on the way and which stay the same?

The logical (IP) source and destination stay A and P end to end. The physical (MAC) source and destination are replaced on every link, because each frame only travels one hop.

Transport Layer

  • The transport layer is responsible for Process-to-Process delivery of the ENTIRE MESSAGE①
  • The network layer handles end-to-end (source-to-destination) delivery of INDIVIDUAL PACKETS; no relationship between packets, each one is considered independently but the transport layer ensures whole message arrives intact and in order②
  • Transport PDU is called SEGMENT
  • Process addressing
    • Port address③
38
Exam weight ●●● High
  1. Transport: process-to-process delivery of the WHOLE message, in order.
  2. The network layer treats every packet independently; transport stitches them back together.
  3. Transport PDU = SEGMENT. Address = PORT number.

Session

  • Setting up, managing, and terminating sessions (connections) between different applications

    • Full/Half duplex: Processes either send and receive data at the same time or at different times
  • Synchronization checkpoints
    • Allow long transmissions to continue from where they were after the connection crash②

      TCP/IP Protocol Suite

      • Developed in 1970s
      • Is a suite of protocols named after the two most important protocols TCP and IP but includes other protocols such as UDP, etc①
      • Consists of Five layers
      • The first four lower layers correspond to the first four layers of the OSI model.
      • The three top layers in the OSI model, however, are represented in TCP/IP by a single layer called the application layer.②
