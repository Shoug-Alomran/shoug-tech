A company connects its office in Riyadh to its office in Dammam (about 400 km away) so employees can share files and printers. What type of network is this?

Size decides the type: LAN = a building or campus, MAN = one city, WAN = across cities or countries. Riyadh to Dammam spans two cities, so it is a WAN. Ownership doesn't decide it.
2.
Ch 1

Two branch offices use a link on which both sides can send and receive at the same moment, like a telephone call. What is this data flow mode?

Full-duplex = both directions at the same time (telephone). Half-duplex = both directions but one at a time (walkie-talkie). Simplex = one direction only (keyboard). Multipoint describes how many devices share a link, not the direction.
3.
Ch 3

In byte-oriented framing, the data contains a byte with the same pattern as the flag. What does the sender do?

Byte stuffing: an ESC byte goes in front of any flag or ESC pattern in the data, and the receiver removes it. Inserting a 0 after five 1s is bit stuffing, used in bit-oriented framing.
4.
Ch 3

A code has a minimum Hamming distance of 4. How many bit errors can it guarantee to DETECT?

To detect s errors you need dmin = s + 1, so s = 4 − 1 = 3. (To correct t errors you need dmin = 2t + 1, so this code corrects only 1.)
5.
Ch 4

A frame arrives with destination address 4A:30:10:21:10:1A. What type of address is it?

Look at the least significant bit of the first byte: 4A = 0100 1010, last bit 0 → unicast. If it were 1, it would be multicast. Broadcast is all Fs.
6.
Ch 6

Which device can join two LAN segments and forward a frame only to the segment where the destination MAC address is?

A switch has a MAC table and filters: it forwards only out of the port where the destination was learned. Hubs and repeaters work at layer 1 and copy bits to every port.
7.
Ch 7

Why does a new computer send its DHCPDISCOVER message as a broadcast?

Before DHCP the client has no IP and doesn't know where the server is, so it uses source 0.0.0.0 and destination 255.255.255.255. Finding a MAC address is ARP's job.
8.
Ch 8

RIP is an example of which routing approach, and what metric does it use?

RIP = distance vector with hop count (maximum 15; 16 = unreachable). OSPF is link state (Dijkstra); BGP is path vector between autonomous systems.
9.
Ch 9

A video-calling application must keep delay low and can tolerate a few lost packets. Which transport protocol suits it?

Real-time audio and video prefer UDP: a retransmitted packet would arrive too late to play. File transfer, email and the web need TCP's reliability.
10.
Ch 10

A local DNS server answers a repeated query for www.psu.edu.sa from its cache. What stops it from using that answer forever?

Cached records carry a TTL set by the authoritative server. When it runs out the entry is dropped, and the next query goes to the hierarchy again.

Ch 3

Stations on a shared Ethernet bus use CSMA/CD.

a) Station A detects a collision while sending. List what it does next, in order. (0.75 mark)

Model answer · 0.75 marks
  1. Stops transmitting its frame.
  2. Sends a short jamming signal so every station knows there was a collision.
  3. Waits a random backoff time (binary exponential backoff, 0 to 2K − 1 slots after K collisions).
  4. Senses the medium again and retries; it gives up after too many attempts.

b) Why must an Ethernet frame be at least 64 bytes? (0.5 mark)

Model answer · 0.5 marks

So the sender is still transmitting when news of a collision gets back. Frame transmission time must be at least twice the maximum propagation time (2 × Tp); otherwise the sender could finish, miss the collision, and think the frame was delivered.

c) In a token passing network, what gives a station the right to send? (0.25 mark)

CSMA/CD: sense → send while monitoring → collision → stop, jam, random backoff, retry. Minimum frame 64 bytes (512 bits) so Tfr ≥ 2Tp. Controlled access: reservation (reserve a slot), polling (poll/select), token passing (the token).

How many bytes is the data field at most, and why is padding added? (0.75 mark)

Model answer · 0.75 marks

The data field carries 46 to 1500 bytes. If the upper-layer data is shorter than 46 bytes, padding is added so the frame reaches the 64-byte minimum.

A student types lms.psu.edu.sa. Nothing is cached.

a) Which label is the top-level domain? Which is the host?

b) Which sequence is a correct iterative lookup?

c) In recursive resolution, who contacts the next server at each step?

d) DNS normally runs over which transport protocol and port?

Read right to left: sa (TLD) → edu → psu → lms (host). Iterative: the local server asks root, then the TLD server, then the authoritative server, each returning a referral. Recursive: each server passes the query on and the answer travels back. DNS queries use UDP port 53 (TCP for zone transfers and large replies).
