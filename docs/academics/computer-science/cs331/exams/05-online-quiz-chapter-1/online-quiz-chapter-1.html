A company has 10 computers that need to be connected in a fully connected mesh topology. How many dedicated links are required?

A fully connected mesh with 10 computers requires 10×9÷2 = 45 dedicated links.

Question 2Mark /1.00

Ch 1

Scenario: Your company needs to set up a network where devices can be easily added or removed, and failure of one device should not affect others. However, if the central connecting point fails, the entire network stops working. Which topology best fits this scenario?

A star topology connects devices through a central connecting point, so failure of that point can stop the network.

Question 3Mark /1.00

Ch 1

In the OSI model, which layer is responsible for moving frames from one hop (node) to the next?

The Data Link layer is responsible for node-to-node delivery of frames.

Question 4Mark /1.00

Ch 1

A user wants to send a large file over the Internet. Which of the following correctly describes the flow of data from the user's application to the network cable?

The OSI data flow toward the medium passes through Application, Presentation, Session, Transport, Network, Data Link, and Physical layers.

Question 5Mark /1.00

Ch 1

Scenario: Two computers are communicating. Computer A is sending data to Computer B. At the Transport layer of Computer A, a TCP header is added. When Computer B receives the data, which layer will read and process this TCP header?

The Transport layer processes the TCP header at the receiving computer.

Question 6Mark /1.00

Ch 1

Which type of network connection uses a dedicated link between exactly two devices?

A point-to-point connection provides a dedicated link between exactly two devices.

Question 7Mark /1.00

Ch 1

What is the PDU (Protocol Data Unit) called at the Network layer of the OSI model?

Packet or datagram is the PDU associated with the Network layer.

Question 8Mark /1.00

Ch 1

The physical layer is responsible for all of the following EXCEPT:

Process-to-process delivery is a Transport layer responsibility, not a Physical layer responsibility.

Question 9Mark /1.00

Ch 1

Scenario: You are downloading multiple files simultaneously from a web server. Which layer of the OSI model is responsible for keeping these different application data separate from each other?

The Session layer is responsible for managing sessions and keeping different application activities logically separate.

Question 10Mark /1.00

Ch 1

In the OSI model, which of the following layers is implemented in hardware (in the Network Interface Card)?

The Physical and Data Link layers are implemented in the network interface hardware.
