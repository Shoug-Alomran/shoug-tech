2. Topologies/5

1.
Topologies

A full mesh of 7 devices needs links, and each device needs I/O ports.

Links = n(n − 1)/2 = 7 × 6 / 2 = 21; ports per device = n − 1 = 6.
2.
Topologies

Topology Links
Star (to a hub)
Ring
Full mesh
Star: one link per device. Ring: n links. Mesh: n(n − 1)/2 = 45.
3.
Topologies

In which topology does one broken cable in the main backbone stop the whole network?

Every device taps the single bus backbone, so a break in it disconnects everyone.
4.
Topologies

Which topology gives privacy, robustness and easy fault isolation but needs the most cabling?

Dedicated links between every pair of devices: robust and private, but expensive.
5.
Topologies

True or false: In a star topology, if the hub fails the whole network fails.

Every link goes through the hub.
