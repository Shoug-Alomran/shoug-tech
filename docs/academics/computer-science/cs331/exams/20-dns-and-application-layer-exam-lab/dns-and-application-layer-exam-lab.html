Rules this lab uses for the DNS drawings (Qimah / Forouzan style)
  • Only boxes with the DNS tag are name servers. Untagged boxes (SA, EDU, CS…) are domain labels and get skipped.
  • The host's local DNS server is the closest DNS-tagged box above it.
  • If the local server is above the target too, it's authoritative and answers directly.
  • Otherwise the lookup starts at Root, then goes down through each DNS-tagged server toward the target.
  • Recursive: host → local → root → … → authoritative, then the answer comes back the same way.
  • Iterative: the host asks each server itself (host → server, server → host), in chain order.
  • Mixed: host → local is recursive; the local server queries the others iteratively (the textbook "in practice" version).
  • Cached: a cached server address lets the local server skip the root. A cached answer means the local server replies at once.
