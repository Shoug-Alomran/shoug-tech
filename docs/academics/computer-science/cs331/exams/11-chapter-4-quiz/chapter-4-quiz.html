3. MAC addresses/3

1.
MAC addresses

An Ethernet address is bits long, written as hexadecimal digits.

6 bytes = 48 bits = 12 hex digits.
2.

Destination address Type

Look at the second hex digit: even (A, 2) = unicast, odd (7) = multicast; all Fs = broadcast.

MAC addresses

True or false: A source MAC address can be a multicast address.

Standards and duplex

Which is NOT needed for full-duplex Ethernet?

With dedicated full-duplex links there are no collisions, so CSMA/CD is turned off.
4.
Standards and duplex

True or false: Half-duplex Ethernet (hub or shared medium) uses CSMA/CD.

Stations share the medium, so collisions are possible and must be detected.
5.
Standards and duplex

Why does Ethernet have a minimum frame length of 64 bytes?

A frame shorter than the round-trip collision window could finish before the collision is heard.
