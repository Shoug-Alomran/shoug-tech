Major I (181) · Short 3 · 2 mk

The Computer A wants to send data to Computer D. Draw the responsibility/scope of Data link layer, Network layer and transport layer in the communication from A to D.

Model answer · 2 marks
  • Data link layer: node to node, once per hop (A to B, B to C, C to D). Unit: frame.
  • Network layer: end to end, host A to host D across all the routers. Unit: packet.
  • Transport layer: process to process, from a process on A to a process on D. Unit: segment.

Briefly write in two lines about attenuation in signals? What devices are used to rectify the problem?

Model answer · 2 marks

Attenuation is the loss of signal energy as the signal travels, because the medium resists it. The signal gets weaker with distance.

Fix: amplifiers boost analog signals. Repeaters regenerate digital signals.

8.
Major I (181) · Short 2 · 2 mk

Differentiate between Propagation time and Transmission time in your own words.

Model answer · 2 marks

Propagation time is how long one bit takes to travel from one node to the next: distance ÷ propagation speed. It depends on distance and the medium.

Transmission time is how long it takes to put the whole message onto the link: message length in bits ÷ bandwidth. It depends on message size and bandwidth.

Major I (181) · Short 4 · 2 mk

Define bandwidth delay product in measuring performance of a channel? What we get in result of this product?

Model answer · 2 marks

Bandwidth-delay product = bandwidth × delay. Think of the link as a pipe: bandwidth is its cross-section and delay is its length.

The result is the number of bits that can fill the link, which is the length of the link in bits.

6.
Quiz 2 · Q7 · 1.5 mk

Briefly write three features added in Stop and Wait protocol to improve the Simple Error and Flow Control Protocol?

Model answer · 1.5 marks
  1. Acknowledgment: the sender sends one frame at a time and waits for an ACK before sending the next (flow control).
  2. Error detection: a CRC is added to each data frame, and a corrupted frame is silently discarded.
  3. Timer and retransmission: the sender keeps a copy and starts a timer. If no ACK arrives before it expires, it resends the frame.

Sequence and acknowledgment numbers are also added so the receiver can spot duplicates.

9.
Major II (181) · Q12 · 1 mk

Write the main difference between CSMA and CSMA/CD?

Model answer · 1 marks

CSMA senses the medium before sending, which reduces collisions, but it has no procedure once a collision happens.

CSMA/CD adds collision detection: the station keeps monitoring while it transmits. On a collision it stops, sends a jamming signal, waits a random backoff time and retries.

Major II (181) · Q13a · 2 mk

A computer in a LAN with Private IP 10.4.4.65 wants to access a web server on internet with IP 200.53.25.67. The gateway of LAN is a router with Public IP 130.50.60.8.

How this computer can access web resources on internet? Write the technique and explain briefly how it works in your own words (minimum 4 lines)?

Model answer · 2 marks

NAT (Network Address Translation). The computer sends the packet to its gateway. The router replaces the private source address 10.4.4.65 with its public address 130.50.60.8 and records the mapping in a translation table, using port numbers (PAT) to tell hosts apart.

When the reply from 200.53.25.67 comes back, the router looks up the table, restores 10.4.4.65 and forwards the packet into the LAN.

10.
Major II (181) · Q13b · 2 mk

A computer in a LAN with Private IP 10.4.4.65 wants to access a web server on internet with IP 200.53.25.67. The gateway of LAN is a router with Public IP 130.50.60.8.

The same computer with IP 10.4.4.65 wants to send data within LAN to a computer with IP 10.4.4.89. How the source computer can get the physical address of that computer? Write the protocol and explain briefly how it works in your own words (4 lines atleast)?

Model answer · 2 marks

ARP (Address Resolution Protocol). The source first checks its ARP cache. If the address is missing, it broadcasts an ARP request asking who has 10.4.4.89.

Every host on the LAN receives it, but only 10.4.4.89 answers, with a unicast ARP reply carrying its MAC address. The source stores the result in its cache and sends the frame.
