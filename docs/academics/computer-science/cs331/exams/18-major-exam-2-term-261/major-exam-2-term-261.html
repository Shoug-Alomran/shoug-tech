Question #1 MCQs [0.5 each, total 3.0 marks]

Please read each scenario and question carefully. Select the best answer from the choices provided (A, B, C, or D).

1.
Ch 6

A company has a computer belonging to the "HR Department" located in a room full of "IT Department" computers. The HR computer needs to be on the same broadcast domain as other HR computers in a different building, but the company does not want to run new physical cables to separate the departments. What is the technology that can solve this issue?

A VLAN groups stations by software configuration, not by where they are plugged in, so no recabling is needed. VLANs create broadcast domains; they don't move wiring, need two NICs or enlarge collision domains.
2.
Ch 7

A network administrator is manually configuring a new desktop computer to connect to the corporate network. The administrator inputs the IP Address 172.16.5.20 and the Subnet Mask 255.255.0.0. However, the computer cannot access the internet, only local network resources. Which crucial piece of information did the administrator likely forget to configure?

Local traffic works with an IP and mask alone. Anything outside the network must go to the router, the default gateway. Without it the host has nowhere to send off-network packets.
3.
Ch 6

A company places its HR and Sales departments in separate VLANs. What is one benefit?

Each VLAN is its own broadcast domain, so HR broadcasts never reach Sales (less traffic, more security). VLANs don't encrypt, remove IP addressing or change cable speed.
4.
Ch 7

When a client requests an IP configuration from a DHCP server, which database does the server check first before selecting an address from the dynamic pool?

A DHCP server has a static database (fixed physical-to-IP bindings) and a dynamic pool. It checks the static database first; only if the client isn't there does it lease a temporary address from the pool.
5.
Ch 7

Why does a NAT-enabled border router inherently provide basic firewall protection for devices on an internal network?

The translation table only gets an entry when an inside host sends first. An unsolicited packet from outside matches no entry, so the router can't tell which private host it is for and drops it. NAT doesn't encrypt or drop UDP.
6.
Ch 6

What is the primary function of Virtual LAN (VLAN) technology, and how does a switch manage device membership?

VLAN = logical LANs on one physical LAN. The switch keeps a table mapping each port (or MAC) to its VLAN. Switches don't use routing tables.

1)
Ch 6

Given eight computers connected to a single switch configured with VLAN 10 (A, B, C), VLAN 20 (D, E, F), and VLAN 30 (G, H), how many broadcast domains exist?

One broadcast domain per VLAN: 3. Without VLANs the switch would be 1 broadcast domain. (8 would be the number of collision domains, one per port.)
2)
Ch 6

If computer A (belonging to VLAN 10) sends an Ethernet broadcast across the switch, which other computers will receive the broadcast?

A broadcast is flooded only to ports in the same VLAN, and never back out the port it arrived on: B and C.
3)
Ch 6

Can computer A communicate directly with computer D using only Layer 2 switching?

Different VLANs = different broadcast domains. Traffic between them needs a router (layer 3). A trunk only carries several VLANs between switches; it doesn't join them.
