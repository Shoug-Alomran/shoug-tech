To separate one frame from another a ________ is added at the beginning and end of the frame.

Check the second hex digit from the left: 2 is even, so the last bit of the first byte is 0 and the address is unicast (Chapter 4 slides, even = unicast, odd = multicast). The graded paper ticked Multicast, which contradicts that rule.

If the receiver using checksum technique gets result a non zero value, the receiver will discard that data word.

The receiver accepts only when the checked result is zero. Any non-zero result means an error, so the data word is discarded.

Reed-Solomon code used today for both detection and correction is a ____ code.

Reed-Solomon is a cyclic code. Block code is the wider family, and a checksum detects errors only.

7.
Ch 3

Briefly write three features added in Stop and Wait protocol to improve the Simple Error and Flow Control Protocol?

Model answer · 1.5 marks
  1. Acknowledgment: the sender sends one frame at a time and waits for an ACK before sending the next (flow control).
  2. Error detection: a CRC is added to each data frame, and a corrupted frame is silently discarded.
  3. Timer and retransmission: the sender keeps a copy and starts a timer. If no ACK arrives before it expires, it resends the frame.

Sequence and acknowledgment numbers are also added so the receiver can spot duplicates.

b. Calculate the minimum Hamming distance of your designed code?

c. How many single bit errors can be detected?

d. If the receiver using this coding scheme gets a codeword with 2 single bits error, will the receiver able to detect it?

Odd parity makes the count of 1s odd in every codeword: 001, 010, 100, 111. Every pair differs in 2 bits, so dmin = 2 and s = dmin − 1 = 1. Two flipped bits keep the count odd, turning one valid codeword into another, so the error goes undetected. The answer sheet appended 1 to every dataword (001, 011, 101, 111), which is not odd parity.
