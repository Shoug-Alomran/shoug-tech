Constructor

Notes

  1. 1

    Constructor: same name as the class, NO return type (not even void), runs when you call new.

  2. 2

    Trap Writing a return type (even void) makes it an ordinary method, not a constructor.

Exam angle

PredictionQ1

Which is true of a constructor?

  1. A class can have only one
  2. It has the same name as the class and no return type
  3. It must return void
  4. It is called with the dot operator
Show answer

B. It has the same name as the class and no return type

Data hiding and data Validation

Notes

  1. 1

    Data hiding lets setters VALIDATE values (e.g., reject a negative age).

Exam angle

PredictionQ1

Why should instance variables be private?

Show answer

So other classes can only change them through methods, which can validate the values (data validation) and hide the implementation; the class can then change internally without breaking its users.

this The Keyword

Notes

  1. 1

    this = the current object. Use it when a parameter has the same name as a field: this.name = name; and to call another constructor: this(...).

Exam angle

PredictionQ1

In a constructor with parameter name, which assigns the field?

  1. Student.name = name;
  2. this.name = name;
  3. name = name;
  4. name = this.name;
Show answer

B. this.name = name;

Static Methods

Notes

  1. 1

PredictionQ1

A static method can directly access instance variables.

Composition

Notes

  1. 1

    Composition = has-a: a class holds an object of another class (Student has a Date).

  2. 2

    Memory trick is-a → inheritance; has-a → composition.

Exam angle

PredictionQ1

A Student class with a Date birthDate field is an example of:

  1. Overloading
  2. Composition (has-a)
  3. Inheritance (is-a)
  4. Polymorphism
Show answer

B. Composition (has-a)
