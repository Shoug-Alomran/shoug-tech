T 1

Classes and objects

Anatomy of a class

public class Student {
    private String name;          // field (encapsulated)
    private static int count = 0; // shared by all objects
    public Student(String name) { // constructor
        this.name = name; count++;
    }
    public String getName() { return name; }      // getter
    public void setName(String n) { name = n; }   // setter
    @Override public String toString() { return "Student " + name; }
}

Key ideas

  • Encapsulation: private fields, public methods.
  • Constructor: same name as the class, no return type. Java gives a no-arg default constructor only if you write none.
  • this refers to the current object; this(...) calls another constructor.
  • static belongs to the class (one copy); instance members belong to each object. A static method cannot use this.
  • Objects are reached through references; null means no object.
Writing void Student() makes a method, not a constructor.
T 2

Interfaces, Comparable and Comparator

Interfaces

A contract of abstract methods (plus default/static methods). A class implements many interfaces but extends only one class. You cannot instantiate an interface.

Comparable (natural order)

public class Student implements Comparable<Student> {
    public int compareTo(Student o) {
        return Double.compare(this.gpa, o.gpa); // <0, 0, >0
    }
}
Collections.sort(list);   // uses compareTo

Comparator (other orders)

Comparator<Student> byName = (a, b) -> a.getName().compareTo(b.getName());
list.sort(byName);
Collections.sort(list, Comparator.comparing(Student::getName));
Comparable is inside the class (one natural order); Comparator is outside (as many orders as you like).
T 3

Files

Text files

  • Read: Scanner sc = new Scanner(new File("in.txt")); while (sc.hasNextLine()) ...
  • Write: PrintWriter pw = new PrintWriter(new FileWriter("out.txt", true)); (true = append). Always close() (or try-with-resources).
  • FileNotFoundException and IOException are checked.

try-with-resources

try (Scanner sc = new Scanner(new File("in.txt"))) { ... } catch (FileNotFoundException e) { ... } closes the file automatically.

Binary / object files

ObjectOutputStream.writeObject(obj) needs the class to implement Serializable; ObjectInputStream.readObject() returns Object (cast it).

T 4

Generic classes

Generic class and method

public class Box<T> {
    private T item;
    public void set(T item) { this.item = item; }
    public T get() { return item; }
}
public static <T extends Comparable<T>> T max(T a, T b) {
    return a.compareTo(b) >= 0 ? a : b;
}

Rules

  • Type parameters take reference types only: Box<Integer>, not Box<int> (autoboxing converts).
  • Compile-time type safety; no casts when reading.
  • Bounded type: <T extends Number>. Wildcards: <?>, <? extends T> (read), <? super T> (write).
List<Integer> is not a subtype of List<Number>. Use List<? extends Number>.
T 5, 9

Inheritance and polymorphism

Inheritance

  • class Dog extends Animal: Dog inherits Animal's non-private members ("is-a").
  • The subclass constructor calls super(...) first (implicitly super() if omitted; error if the parent has no no-arg constructor).
  • super.method() calls the parent's version. protected = visible to subclasses and the package.
  • Every class extends Object (toString, equals, hashCode).

Overriding vs overloading

  • Override: same signature in the subclass; chosen at run time by the actual object (dynamic binding). Use @Override.
  • Overload: same name, different parameters; chosen at compile time.
  • final method cannot be overridden; final class cannot be extended.

Polymorphism

Animal a = new Dog(); a.speak(); runs Dog's speak (actual type). But a.fetch() does not compile if only Dog has fetch (declared type decides what you may call).

  • Downcast: if (a instanceof Dog) ((Dog) a).fetch();
  • Wrong downcast → ClassCastException at run time.
Declared type decides what you may call; actual type decides which version runs.

Abstract classes

abstract class Shape { abstract double area(); }: cannot be instantiated; subclasses must implement area() or be abstract themselves. Can have fields and constructors (unlike interfaces).

Iterating

  • for-each: for (String s : list).
  • Removing while iterating: use Iterator it = list.iterator(); while (it.hasNext()) if (...) it.remove();
Calling list.remove(x) inside a for-each throws ConcurrentModificationException. On an ArrayList<Integer>, remove(1) removes index 1; use remove(Integer.valueOf(1)) for the value.

Your own linked list

class Node<T> { T data; Node<T> next; }
void addFirst(T x) { Node<T> n = new Node<>(); n.data = x; n.next = head; head = n; size++; }
void print() { for (Node<T> c = head; c != null; c = c.next) System.out.println(c.data); }
Always handle the empty list (head == null) and the single-node case.

Map patterns

map.put(k, map.getOrDefault(k, 0) + 1); counts frequencies. for (Map.Entry<K,V> e : map.entrySet()) iterates pairs.

T 10, Ch 8

Recursion and 2D arrays

Recursion

  • A base case that stops it and a recursive case that moves toward it.
  • factorial(n) = n × factorial(n − 1), factorial(0) = 1.
  • fib(n) = fib(n−1) + fib(n−2): exponential without memoization.
  • Missing base case → StackOverflowError.

Trace example

int f(int n) { if (n <= 1) return 1; return n + f(n - 2); }
f(6) = 6 + f(4) = 6 + 4 + f(2) = 6 + 4 + 2 + f(0) = 13

2D arrays

  • int[][] m = new int[3][4]; 3 rows, 4 columns. m.length rows, m[0].length columns.
  • Row-major loops: for r … for c … m[r][c].
  • Ragged arrays: rows can have different lengths.
