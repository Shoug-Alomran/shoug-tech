2. Layered Approach

Notes

  1. 1

    Layered: layer 0 = hardware … layer N = UI; each uses only the layers below. Advantage: easy debugging and maintenance. Disadvantage: hard to define layers, overhead.

Exam angle

Past exam · Quiz 1 (Ch. 1 & 2)

Q33: advantage of layering

PredictionQ1

Give one advantage of the layered approach.

Compare with the model answer

Simple construction and debugging: each layer is debugged on top of already-verified lower layers, so an error is found in the layer being tested; layers can also be changed independently.

3. Microkernel System Structure

Slide 24 / 27

Microkernel System Structure

Notes

  1. 1

    Microkernel: move most services into user space; communicate by message passing. + easier to extend, port, more reliable and secure. − message-passing overhead.

Exam angle

Past exam · Quiz 1 (Ch. 1 & 2)

PredictionQ2

Give one disadvantage of the microkernel approach.

Compare with the model answer

Performance overhead: user-space services communicate through the kernel by message passing, which costs extra copies and context switches.

Slide 25 / 27

Modules

Notes

  1. 1

    Loadable kernel modules: core kernel + modules loaded as needed (like layers but any module can call any other).

Hybrid Systems

Notes

  1. 1

    Hybrid systems mix structures: Linux/Solaris monolithic + modules; Windows mostly monolithic + microkernel parts; macOS/iOS Mach + BSD.
