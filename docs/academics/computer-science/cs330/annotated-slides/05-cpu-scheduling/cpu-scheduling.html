Preemptive and Nonpreemptive Scheduling

Notes

  1. 1

    Scheduling decisions when a process: 1) running → waiting, 2) running → ready, 3) waiting → ready, 4) terminates. Only 1 and 4 → nonpreemptive; otherwise preemptive.

Exam angle

PredictionQ1

Under nonpreemptive scheduling, the CPU is taken from a process only when it:

  1. Terminates or switches to waiting
  2. An interrupt occurs
  3. Uses up its time quantum
  4. A higher-priority process arrives
Show answer

A. Terminates or switches to waiting

Dispatcher

Notes

  1. 1

    Dispatcher gives the CPU to the chosen process: context switch, switch to user mode, jump to the right instruction. Dispatch latency = time to do this.

Slide 10 / 45

Scheduling Criteria

Notes

  1. 1

    Maximize CPU utilization and throughput; minimize turnaround, waiting and response time.

  2. 2

    Tip Waiting time = turnaround − burst. Turnaround = completion − arrival. Response = first run − arrival. Draw the Gantt chart first.

Exam angle

PredictionQ1

Which criterion should be MINIMIZED?

  1. Waiting time
  2. Throughput
  3. CPU utilization
  4. All of these
Show answer

A. Waiting time

First- Come, First-Served (FCFS) Scheduling

Notes

  1. 1

    FCFS: run in arrival order; nonpreemptive. Convoy effect: short processes wait behind a long one.

Exam angle

PredictionQ1

P1 = 24, P2 = 3, P3 = 3 arrive in that order at time 0. FCFS average waiting time:

  1. 10
  2. 27
  3. 3
  4. 17
Show answer

D. 17 — (0 + 24 + 27) / 3.

Slide 13 / 45

FCFS Scheduling (Cont.)

Notes

  1. 1

    Order P2, P3, P1 gives average wait (6 + 0 + 3) / 3 = 3: order matters a lot.

Slide 14 / 45

Shortest-Job-First (SJF) Scheduling

Notes

  1. 1

    SJF: run the shortest next CPU burst. Optimal: minimum average waiting time for a given set. Problem: you can’t know the next burst length.

Exam angle

PredictionQ1

SJF gives the minimum average waiting time for a given set of processes.

Show answer

True

Determining Length of Next CPU Burst

Notes

  1. 1

    Predict the next burst: τₙ₊₁ = α·tₙ + (1 − α)·τₙ (exponential averaging), usually α = ½.

Exam angle

PredictionQ1

τ₀ = 10, α = 0.5, the actual burst t₀ = 6. τ₁ =

  1. 10
  2. 6
  3. 8
  4. 16
Show answer

C. 8 — 0.5·6 + 0.5·10.

Shortest Remaining Time First Scheduling

Notes

  1. 1

    SRTF = preemptive SJF: a new arrival with a shorter burst than the remaining time preempts the running process.

  2. 2

    Trap In SRTF compare the newcomer with the REMAINING time of the running process, not its original burst.

Round Robin (RR)

Notes

  1. 1

    Round Robin: each process gets a time quantum q, then goes to the back of the ready queue. No process waits more than (n − 1)q.

Exam angle

PredictionQ1

P1 = 24, P2 = 3, P3 = 3, RR with q = 4. P1 completes at time:

  1. 26
  2. 24
  3. 28
  4. 30
Show answer

D. 30 — P1 runs 0–4, P2 4–7, P3 7–10, then P1 alone until 30.

Time Quantum and Context Switch Time

Notes

  1. 1

    Large q → behaves like FCFS. Small q → too many context switches. q should be large compared with the context-switch time (80% of bursts < q).

Exam angle

PredictionQ1

If the RR time quantum is very large, RR behaves like:

  1. Priority
  2. SJF
  3. FCFS
  4. SRTF
Show answer

C. FCFS

Multilevel Feedback Queue

Notes

  1. 1

    Multilevel feedback queue: processes MOVE between queues (demote CPU-hogs, age old ones up).

Exam angle

What distinguishes a multilevel FEEDBACK queue from a multilevel queue?

  1. It never preempts

  3. Processes can move between queues
  4. It has more queues
Show answer

C. Processes can move between queues
