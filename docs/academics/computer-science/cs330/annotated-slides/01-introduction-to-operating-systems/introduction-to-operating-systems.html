                                            🎯 How this can come up · 1 question
                                            Written

                                            What is the difference between multiprogramming and time-sharing?

                                            Multiprogramming organizes jobs so the CPU always has one to execute: when a job waits (e.g. for I/O) the OS switches to another, increasing CPU utilization. Time-sharing extends this by switching so frequently that users can interact with each program while it runs (interactive computing, short response time).

                                            Exam weight ●○○ Low
