Process Management

The process concept and its memory layout, process states and the PCB, scheduling queues and schedulers, context switches, process creation (fork/exec) and termination, and interprocess communication with shared memory (bounded buffer) and message passing.

Bounded-Buffer – Shared-Memory Solution

Notes

  1. 1

    Circular bounded buffer: in = next free slot, out = first full slot. Empty when in out; full when (in + 1) % SIZE out, so only SIZE − 1 items fit.

Exam angle
