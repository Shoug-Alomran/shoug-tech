Slide 44 / 83

Pass By Value

Exam angle

PredictionQ1

Why can a method change the elements of an array passed to it, but not an int passed to it?

Compare with the model answer

Both are passed by value, but for an array the value is a reference to the same array object on the heap; changes to its elements are visible to the caller. For an int the method only gets a copy of the value.
