Notes

Slide 40 / 61

Pass by Value

Notes

  1. 1

    Pass by value: the method gets a COPY; changing the parameter doesn’t change the caller’s variable.

Exam angle

PredictionQ1

A method increments its int parameter. Does the caller’s variable change? Why?

Compare with the model answer

No. Java passes primitives by value: the method works on a copy, so the caller’s variable keeps its original value.

Overloading Methods

Notes

  1. 1

    Overloading: same name, different parameter lists (max(int,int), max(double,double)).

  2. 2

    Trap Different return type alone does NOT overload a method.

Exam angle

Two methods can be overloaded if they differ only in return type.

  2. Parameter lists must differ.
