Slide 36 / 50

Caution

Notes

  1. 1

    Caution: a semicolon right after for (...) ; makes an empty body.

Exam angle

PredictionQ1

What is wrong with: for (int i = 0; i < 10; i++); { System.out.println("i is " + i); }

Show answer

The semicolon gives the loop an empty body; the block runs once afterwards (and i is out of scope there, so it does not even compile).

Slide 49 / 50

Write a program to get a number from user and test whether it is prime or not. An integer greater than 1 is prime if its only positive divisor is 1 or itself. For example, 2, 3, 5, and 7 are prime numbers, but 4, 6, 8, and 9 are not

Notes

  1. 1

    Prime test: divide by 2 … sqrt(n); prime if no divisor found.

Exam angle

PredictionQ1

Write a loop that checks whether n > 1 is prime.

Show answer

boolean isPrime = true; for (int d = 2; d <= Math.sqrt(n); d++) { if (n % d == 0) { isPrime = false; break; } }
