Slide 21 / 62

Common Errors

Notes

  1. 1

    Common error: a semicolon after if (radius >= 0); makes an empty body.

Exam angle

PredictionQ1

What is wrong with: if (radius >= 0); { area = radius * radius * PI; }

Show answer

The semicolon ends the if with an empty statement, so the block always runs regardless of the condition.

What happens if you omit break in a switch case?

Show answer

Execution falls through and the statements of the following cases run as well, until a break or the end of the switch.
