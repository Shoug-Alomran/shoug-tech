CH 1–2

Java basics and elementary programming

Program structure

  • Source .java → javac compiles to bytecode .class → the JVM runs it (write once, run anywhere).
  • public static void main(String[] args) is the entry point; the class name must match the file name.
  • Errors: syntax (compile), runtime (crash, e.g. divide by zero), logic (wrong output).

Primitive types

TypeSizeExample
byte / short / int / long1 / 2 / 4 / 8 bytesint x = 5; long y = 5L;
float / double4 / 8 bytes3.5f, 3.5
char2 bytes (Unicode)'A' (65)
boolean–true, false

Operators and casting

  • / on two ints is integer division: 7 / 2 = 3; 7 / 2.0 = 3.5. % remainder: 7 % 2 = 1, −7 % 2 = −1.
  • Widening is automatic (int → double); narrowing needs a cast: (int) 3.9 = 3 (truncates).
  • i++ uses then increments; ++i increments then uses.
  • Compound: x += 2 means x = x + 2 (with an implicit cast).
int a = 5; int b = a++ + ++a; → 5 + 7 = 12, and a ends at 7.

Input and constants

  • Scanner in = new Scanner(System.in); int n = in.nextInt(); String s = in.nextLine();
  • final double PI = 3.14159; constants in UPPER_CASE.
  • Identifiers: letters, digits, _ and $, cannot start with a digit or be a keyword.
After nextInt(), a following nextLine() reads the leftover newline and returns "".
CH 03

Selections

if / else / switch

  • if (cond) {...} else if {...} else {...}
  • switch (x) { case 1: ...; break; default: ... }: without break execution falls through to the next case.
  • Conditional operator: max = (a > b) ? a : b;

Boolean logic

  • && and || short-circuit: (x != 0 && 10 / x > 1) is safe.
  • Precedence: ! > relational > == > && > ||.
  • De Morgan: !(a && b) = !a || !b.
if (x = 5) does not compile in Java (int is not boolean); if (x == 5) is meant. A ; right after if (...) ends the if.

Dangling else

An else belongs to the nearest unmatched if, whatever the indentation says. Use braces.

CH 04

Math, characters and strings

Math class

Math.pow(2, 3) = 8.0 (double) · Math.sqrt(16) = 4.0 · Math.abs(-3) · Math.max/min · Math.round(2.5) = 3 · Math.ceil(2.1) = 3.0 · Math.floor(2.9) = 2.0 · Math.random() in [0, 1).

Random int in [a, b]: a + (int)(Math.random() * (b - a + 1)).

char

Chars are numbers: 'A' = 65, 'a' = 97, '0' = 48. (char)('A' + 2) = 'C'. '5' - '0' = 5. Character.isDigit(c), isLetter, toUpperCase.

String methods

length() · charAt(i) · substring(a, b) (a inclusive, b exclusive) · indexOf("x") (−1 if absent) · toUpperCase() · trim() · equals() · equalsIgnoreCase() · compareTo() (negative, 0, positive) · contains.

Compare strings with .equals, never == (which compares references). Strings are immutable: s.toUpperCase() alone does not change s.

Concatenation order

"1" + 2 + 3 = "123" but 1 + 2 + "3" = "33" (left to right).

CH 05

Loops

Three loops

  • while (cond) {...}: may run 0 times.
  • do {...} while (cond);: runs at least once.
  • for (int i = 0; i < n; i++) {...}: counter loops.
  • break leaves the loop; continue skips to the next iteration.

Tracing a loop

Make a table with one column per variable and one row per iteration, including the final check that ends the loop.
int sum = 0;
for (int i = 1; i <= 4; i++) sum += i;
i:   1  2  3  4  5 (stop)
sum: 1  3  6  10      -> prints 10

Off-by-one and nesting

  • i < n runs n times from 0; i <= n runs n + 1 times.
  • Nested loops multiply: outer n × inner m iterations.
for (int i = 0; i < 5; i++); with a semicolon runs an empty body; the block after runs once.
CH 06

Methods

Defining methods

public static int max(int a, int b) { return a > b ? a : b; }

  • void methods return nothing. A non-void method must return on every path.
  • Parameters are local; the caller's arguments are copied (pass by value).

Overloading and scope

  • Overloading: same name, different parameter lists (return type alone is not enough).
  • A local variable's scope is the block where it is declared.

Pass by value

Changing a primitive parameter inside a method does not change the caller's variable. But an array parameter refers to the same array, so changing its elements does affect the caller.
CH 07

Single-dimensional arrays

Basics

  • int[] a = new int[5]; default values 0 (false, null for objects). int[] b = {1, 2, 3};
  • Indices 0 to a.length - 1; a[5] on length 5 → ArrayIndexOutOfBoundsException.
  • Enhanced for: for (int x : a) sum += x; (read only).

Common algorithms

  • Sum/average, max/min with an index, reverse (swap i and n−1−i up to the middle).
  • Linear search O(n); binary search O(log n) on a sorted array.
  • Selection sort; Arrays.sort(a), Arrays.toString(a).

Copying

int[] b = a; copies the reference (both names, one array). Real copy: loop, System.arraycopy, or a.clone().

CH 12

Exceptions and text I/O

try / catch / finally

try { ... } catch (ArithmeticException e) { ... } finally { ... }: finally always runs. Catch specific exceptions before general ones (Exception last).

Checked vs unchecked

  • Checked (IOException, FileNotFoundException): must be caught or declared with throws.
  • Unchecked (RuntimeException: ArithmeticException, NullPointerException, ArrayIndexOutOfBounds, NumberFormatException): programming errors.
  • throw new IllegalArgumentException("msg");

Files

  • Write: PrintWriter out = new PrintWriter("data.txt"); out.println(x); out.close();
  • Read: Scanner in = new Scanner(new File("data.txt")); while (in.hasNext()) { ... }
  • Forgetting close() may leave the file empty.
