            1. Sum example: 1 + 2 + … + n = n(n + 1)/2. Add (k + 1) to both sides of P(k).
            🎯 How this can come up · 1 question
            Written

            Prove 1 + 2 + … + n = n(n + 1)/2 for n ≥ 1.

            Basis: n = 1: 1 = 1·2/2. Inductive step: assume 1 + … + k = k(k + 1)/2. Then 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2, which is P(k + 1). So P(n) holds for all n ≥ 1.
