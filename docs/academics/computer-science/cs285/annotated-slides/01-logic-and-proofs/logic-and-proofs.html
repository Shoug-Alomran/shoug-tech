Propositions

Notes

  1. 1

    A proposition is a declarative sentence that is either true or false, not both. Questions, commands and "x + 1 = 2" (x unknown) are NOT propositions.

Exam angle

PredictionQ1

Which of these is a proposition?

  1. What time is it?
  2. Close the door.
  3. 5 + 2 = 8
  4. x + 1 = 2
Show answer

C. 5 + 2 = 8 — It is false, but it is still a declarative sentence with a truth value.

Implication

Notes

  1. 1

    p → q is FALSE only when p is true and q is false. Same as ¬p ∨ q, and as its contrapositive ¬q → ¬p.

  2. 2

    Readings: "if p then q", "p only if q", "q whenever p", "q is necessary for p", "p is sufficient for q".

  3. 3

    Trap "p only if q" is p → q, NOT q → p.

Exam angle

PredictionQ1

When is p → q false?

  1. p false, q true
  2. p true, q false
  3. Both true
  4. Both false
Show answer

B. p true, q false

PredictionQ2

If p is false, p → q is true no matter what q is.

Show answer

True — A false hypothesis makes the implication vacuously true.

Different Ways of Expressing p q

Notes

  1. 1

    From p → q: converse q → p, inverse ¬p → ¬q, contrapositive ¬q → ¬p.

  2. 2

    Only the contrapositive is equivalent to the original; the converse and inverse are equivalent to each other.

  3. 3

    Memory trick CONtrapositive = CONverse + inverse together (swap AND negate).

Exam angle

PredictionQ1

The contrapositive of "If it rains, then I stay home" is:

  1. If it doesn’t rain, then I don’t stay home
  2. If I don’t stay home, then it doesn’t rain
  3. If I stay home, then it rains
  4. It rains and I don’t stay home
Show answer

B. If I don’t stay home, then it doesn’t rain

PredictionQ2

An implication is logically equivalent to its converse.

Show answer

False — It is equivalent to its contrapositive.

Biconditional

Notes

  1. 1

    p ↔ q is true when p and q have the SAME truth value ("if and only if", "necessary and sufficient").

Exam angle

PredictionQ1

p ↔ q is equivalent to:

  1. (p → q) ∨ (q → p)
  2. ¬p ∨ q
  3. (p → q) ∧ (q → p)
  4. p ⊕ q
Show answer

C. (p → q) ∧ (q → p)

Precedence of Logical Operators

Notes

  1. 1

    Precedence: ¬ first, then ∧, then ∨, then →, then ↔. So p ∨ q → ¬r means (p ∨ q) → (¬r).

Exam angle

PredictionQ1

p ∧ q ∨ r is read as:

  1. p ∧ (q ∨ r)
  2. (p ∨ r) ∧ q
  3. (p ∧ q) ∨ r
  4. It is ambiguous
Show answer

C. (p ∧ q) ∨ r — ∧ binds tighter than ∨.

Consistent System Specifications

Notes

  1. 1

    A set of specifications is consistent if ONE assignment of truth values makes all of them true at the same time.

Exam angle

PredictionQ1

How do you check that a list of system specifications is consistent?

Show answer

Translate each into propositional logic and look for one truth assignment (a row of the truth table) that makes every specification true at once. If such a row exists the specs are consistent; if none exists they are inconsistent.

Tautologies, Contradictions, and Contingencies

Notes

  1. 1

    Tautology: always true (p ∨ ¬p). Contradiction: always false (p ∧ ¬p). Contingency: neither.

Exam angle

PredictionQ1

p ∨ ¬p is a:

  1. Contradiction
  2. Tautology
  3. Biconditional
  4. Contingency
Show answer

B. Tautology

PredictionQ2

(p → q) ∧ p ∧ ¬q is a:

  1. Contingency
  2. Tautology
  3. Proposition with no truth value
  4. Contradiction
Show answer

D. Contradiction — p and ¬q make p → q false.

De Morgan’s Laws

Notes

  1. 1

    De Morgan: ¬(p ∧ q) ≡ ¬p ∨ ¬q and ¬(p ∨ q) ≡ ¬p ∧ ¬q.

  2. 2

    Memory trick Negate each part and FLIP the operator.

Exam angle

PredictionQ1

¬(p ∨ q) is equivalent to:

  1. ¬p ∧ ¬q
  2. p ∧ q
  3. ¬p → q
  4. ¬p ∨ ¬q
Show answer

A. ¬p ∧ ¬q

Equivalence Proofs

Notes

  1. 1

    Equivalence proof: rewrite step by step, naming the law used at each step (no truth table).

Exam angle

PredictionQ1

Show that ¬(p → q) ≡ p ∧ ¬q without a truth table.

Show answer

¬(p → q) ≡ ¬(¬p ∨ q) (implication law) ≡ ¬¬p ∧ ¬q (De Morgan) ≡ p ∧ ¬q (double negation).

Notes

  1. False, counterexample x = 0
  2. True
  3. False, counterexample x = −1

Multiple Quantifiers

Notes

  1. 1

    Nested quantifiers: order matters when they differ. ∀x ∃y (x + y = 0) is true over the integers; ∃y ∀x (x + y = 0) is false.

Exam angle

PredictionQ1

Domain: integers. Which is TRUE?

  1. ∀x ∃y (x + y = 0)
  2. ∀x ∀y (x < y)
  3. ∃x ∀y (x < y)
  4. ∃y ∀x (x + y = 0)
Show answer

A. ∀x ∃y (x + y = 0) — Each x has its own y = −x; no single y works for all x.

Notes

    Modus ponens: p, p → q ∴ q.

PredictionQ1

"If it snows, school closes. It snows. Therefore school closes." uses:

  1. Addition
  2. Modus ponens
  3. Hypothetical syllogism
  4. Modus tollens

B. Modus ponens

Slide 116 / 132

Modus Tollens

Notes

  1. 1

    Modus tollens: ¬q, p → q ∴ ¬p.

  2. 2

    Trap p → q, q ∴ p is the fallacy of affirming the conclusion; p → q, ¬p ∴ ¬q is denying the hypothesis. Neither is valid.

Exam angle

PredictionQ1

From p → q and ¬q we may conclude:

  1. p
  2. q
  3. ¬p
  4. Nothing
Show answer

C. ¬p — Modus tollens.

Resolution

Notes

  1. 1

    Resolution: p ∨ q, ¬p ∨ r ∴ q ∨ r (the clashing literal p cancels).

Exam angle

PredictionQ1

  1. q ∧ r
  2. p ∨ r
  3. ¬q ∨ r
  4. q ∨ r
Show answer

D. q ∨ r

Slide 123 / 132

Using the rules of inference to build arguments

Notes

  1. 1

    Build an argument as a numbered list of steps, each a premise or a rule applied to earlier steps.

Exam angle

PredictionQ1

Premises: p → q, q → r, p. Show r with rules of inference.

Show answer

1. p → q (premise) 2. q → r (premise) 3. p → r (hypothetical syllogism 1, 2) 4. p (premise) 5. r (modus ponens 3, 4).
