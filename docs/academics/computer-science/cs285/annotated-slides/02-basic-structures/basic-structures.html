Universal Set and Empty Set

Notes

  1. 1

    Universal set U holds everything under discussion; ∅ = {} has no elements, and {∅} is NOT empty (it has one element).

  2. 2

Power Sets

Notes

  1. 1

    Power set P(A) = the set of all subsets of A. If |A| = n then |P(A)| = 2ⁿ.

Exam angle

PredictionQ1

If A = {a, b, c}, |P(A)| is:

  1. 3
  2. 8
  3. 6
  4. 9
Show answer

B. 8 — 2³ = 8, including ∅ and A.

PredictionQ2

P(∅) equals:

  1. {∅}
  2. ∅
  3. {}
  4. ∅
Show answer

A. {∅} — The only subset of ∅ is ∅ itself.

Functions

Notes

  1. 1

    A function f: A → B assigns EXACTLY ONE element of B to each element of A. A is the domain, B the codomain, f(A) the range.

  2. 2

    Trap Range ⊆ codomain; they are not always equal.

  3. Codomain

Injections

Notes

  1. 1

    One-to-one (injective): f(a) = f(b) ⇒ a = b, no two inputs share an output.

Slide 63 / 145

Surjections

Notes

  1. 1

    Onto (surjective): every b in the codomain is hit by some a.

Slide 64 / 145

Bijections

Notes

  1. 1

    Bijection: one-to-one AND onto; only bijections have inverses.

Exam angle

PredictionQ1

f: ℤ → ℤ, f(x) = x + 1 is:

  1. One-to-one but not onto
  2. Neither
  3. A bijection
  4. Onto but not one-to-one
Show answer

C. A bijection

PredictionQ2

f: ℤ → ℤ, f(x) = 2x is:

  1. Neither
  2. A bijection
  3. Onto but not one-to-one
  4. One-to-one but not onto
Show answer

D. One-to-one but not onto — Odd numbers are never hit.

PredictionQ3

f: ℝ → ℝ, f(x) = x² is:

  1. One-to-one only
  2. Onto only
  3. A bijection
  4. Neither one-to-one nor onto
Show answer

D. Neither one-to-one nor onto — f(−1) = f(1), and negatives are never hit.

Inverse Functions

Notes

  1. 1

    Inverse f⁻¹(b) = a when f(a) = b; exists only for bijections.

Exam angle

PredictionQ1

Find the inverse of f: ℝ → ℝ, f(x) = 3x − 2.

Show answer

Let y = 3x − 2, so x = (y + 2)/3; f⁻¹(y) = (y + 2)/3. It exists because f is a bijection.

Composition

Notes

  1. 1

    (f ∘ g)(x) = f(g(x)): apply g FIRST.

  2. 2

    Trap f ∘ g ≠ g ∘ f in general.

  2. 6x + 7
  3. 6x + 11
  4. 6x² + 13x + 6
Show answer

B. 6x + 7 — f(3x + 2) = 2(3x + 2) + 3.
