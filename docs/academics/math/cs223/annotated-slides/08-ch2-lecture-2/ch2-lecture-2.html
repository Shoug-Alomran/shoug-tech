          1. Invertible Matrix Theorem (n×n A): A invertible ⇔ n pivots ⇔ A ~ I ⇔ Ax = 0 has only the trivial solution ⇔ columns linearly independent ⇔ columns span ℝⁿ ⇔ Ax = b has a unique solution for every b ⇔ det A ≠ 0 ⇔ 0 is not an eigenvalue ⇔ rank A = n.
