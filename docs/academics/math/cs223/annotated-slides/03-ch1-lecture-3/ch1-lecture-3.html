                        🎯 How this can come up · 1 question
                        Written

                        How do you decide whether b is a linear combination of a₁ and a₂?

                        Row reduce [a₁ a₂ | b]. If the system is consistent (no row [0 0 | nonzero]), b is a linear combination and the solution gives the weights; otherwise it is not.
