  1. Cramer's rule: xᵢ = det Aᵢ(b) / det A, where Aᵢ(b) replaces column i with b. A⁻¹ = (1/det A)·adj A, adj A = transpose of the cofactor matrix.

Use Cramer's rule: 3x₁ − 2x₂ = 6, −5x₁ + 4x₂ = 8.

det A = 12 − 10 = 2. det A₁ = 6·4 − (−2)·8 = 40 → x₁ = 20. det A₂ = 3·8 − 6·(−5) = 54 → x₂ = 27.
