                                1. Gauss–Seidel: same formula but uses each NEW component as soon as it is computed; usually converges faster.
                                Memory trickJacobi = all old values; Gauss–Seidel = newest values immediately.
                                🎯 How this can come up · 1 question
                                Written

                                One Jacobi step for 4x − y = 3, x + 5y = 6 from (0, 0).

                                x = (3 + y)/4 = 0.75, y = (6 − x)/5 = 1.2 using the old x = 0, so (0.75, 1.2). (Gauss–Seidel would use x = 0.75: y = (6 − 0.75)/5 = 1.05.)
