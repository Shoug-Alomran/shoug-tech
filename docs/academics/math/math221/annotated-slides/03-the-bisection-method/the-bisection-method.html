The Bisection Method

The bisection method: halving [a, b] on the sign change, stopping criteria and the error bound |pₙ − p| ≤ (b − a)/2ⁿ.

Exam weight ●●● High
  1. Bisection: pₙ = (aₙ + bₙ)/2; keep the half where f changes sign. Always converges (slowly, linearly).
TipError bound: |pₙ − p| ≤ (b − a)/2ⁿ. To reach tolerance ε, need n ≥ log₂((b − a)/ε).
🎯 How this can come up · 2 questions
MCQ

How many bisection steps on [1, 2] guarantee an error below 10⁻³?

2⁻ⁿ < 10⁻³ ⇒ n ≥ 10.

Written

Do one bisection step for f(x) = x³ + 4x² − 10 on [1, 2].

f(1) = −5 < 0, f(2) = 14 > 0. p₁ = 1.5, f(1.5) = 2.375 > 0, so the root is in [1, 1.5].
