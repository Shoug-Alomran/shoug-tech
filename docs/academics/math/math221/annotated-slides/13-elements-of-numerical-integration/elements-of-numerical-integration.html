      1. Trapezoidal: ∫ₐᵇ f ≈ (h/2)(f(a) + f(b)), h = b − a; exact for degree ≤ 1.
      2. Simpson's: ∫ ≈ (h/3)(f(x₀) + 4f(x₁) + f(x₂)), h = (b − a)/2; exact for degree ≤ 3.
      Exam trapSimpson's rule has degree of precision 3, not 2.
