QUESTION 016 POINTS

Given $y=-x^2+3x+6$:

  1. a) For what value(s) of $x$ is $y=-4$?
  2. b) For what value(s) of $x$ is $y\ge 2$?
  3. c) Does $y$ have a minimum or maximum? Find it.
Model answer · Question 1
  1. Set $-x^2+3x+6=-4$. Then $x^2-3x-10=0=(x-5)(x+2)$, so $x=-2$ or $x=5$.
  2. $-x^2+3x+6\ge2$ gives $(x+1)(x-4)\le0$. Thus $-1\le x\le4$.
  3. The parabola opens downward. Its vertex is at $x=-b/(2a)=3/2$, where $y=33/4$. The maximum is $33/4$ at $(3/2,33/4)$; there is no minimum.

QUESTION 028 POINTS
  1. a) Find an equation of the line through $(2,-2)$ and $(6,4).$
  2. b) State the geometric property common to every line in the family $kx+3y-6=0$.
Model answer · Question 2
  1. The slope is $m=(4+2)/(6-2)=3/2$. Using $(2,-2)$, $y+2=\frac32(x-2)$, so $y=\frac32x-5$.
  2. Every line passes through $(0,2)$ because substituting $x=0,y=2$ gives $0+6-6=0$ for every $k$. The family is concurrent at $(0,2)$.

QUESTION 038 POINTS

Find the natural domain of each function:

  1. a) $f(x)=\dfrac{\sqrt{x^2-1}}{x-3}$
  2. b) $f(x)=\dfrac{x+2}{x^2+3x-10}$
Model answer · Question 3
  1. Require $x^2-1\ge0$ and $x\ne3$. Therefore the domain is $(-\infty,-1]\cup[1,3)\cup(3,\infty)$.
  2. Factor the denominator: $x^2+3x-10=(x+5)(x-2)$. Exclude its zeros, so the domain is $\mathbb R\setminus\{-5,2\}$.

QUESTION 048 POINTS

Use the definition of the limit to prove $\lim_{x\to2}2x^2=8$.

Model answer · Question 4
Let $\varepsilon>0$ and choose $\delta=\min(1,\varepsilon/10)$. If $0<|x-2|<\delta$, then $|x+2|<5$, so $|2x^2-8|=2|x-2||x+2|<10|x-2|<10\delta\le\varepsilon$. This proves the limit by the $\varepsilon$-$\delta$ definition.

QUESTION 056 POINTS

Write $f(x)=2|x-3|-3|x+4|$ in piecewise form without absolute values.

Model answer · Question 5
  • If $x<-4$: $|x-3|=3-x$ and $|x+4|=-x-4$, so $f(x)=x+18$.
  • If $-4\le x<3$: $|x-3|=3-x$ and $|x+4|=x+4$, so $f(x)=-5x-6$.
  • If $x\ge3$: both expressions are positive inside the absolute value, so $f(x)=-x-18$.
Thus $f(x)=\begin{cases}x+18,&x<-4,\\-5x-6,&-4\le x<3,\\-x-18,&x\ge3.\end{cases}$

QUESTION 066 POINTS

Given $f(x)=3x^2-x+1$ and $g(x)=\dfrac2{x-3}$, find:

  1. a) $(f\circ g)(2)$
  2. b) $(g\circ f)(2)$
Model answer · Question 6
  1. $g(2)=-2$, then $f(-2)=3(4)+2+1=15$. Thus $(f\circ g)(2)=15$.
  2. $f(2)=12-2+1=11$, then $g(11)=2/(11-3)=1/4$. Thus $(g\circ f)(2)=1/4$.

QUESTION 0718 POINTS

Find each limit:

  1. a) $\lim_{x\to3}\dfrac{x}{x-3}$
  2. b) $\lim_{x\to4}\dfrac{3-x}{x^2-2x-8}$
  3. c) $\lim_{x\to4}\dfrac{x-4}{\sqrt{x+5}-3}$
  4. d) $\lim_{x\to1}\dfrac{x^2-3x+2}{x^2-1}$
  5. e) $\lim_{x\to\infty}\dfrac{4x^3+5}{-6x^2-7x}$
  6. f) $\lim_{x\to\infty}(\sqrt[4]{x^4-x^2}-x^2)$
Model answer · Question 7
  1. The numerator tends to $3$ while the denominator changes sign through $0$. The one-sided limits are $-\infty$ and $+\infty$, so the two-sided limit does not exist.
  2. Factor the denominator as $(x-4)(x+2)$. The numerator tends to $-1$, so the one-sided limits have opposite signs; the two-sided limit does not exist.
  3. Rationalize: $\dfrac{x-4}{\sqrt{x+5}-3}=\sqrt{x+5}+3$ for $x\ne4$. The limit is $6$.
  4. Factor and cancel: $\dfrac{(x-1)(x-2)}{(x-1)(x+1)}$. Substitution gives $(-1)/2$.
  5. The leading terms give $-(2/3)x$, which tends to $-\infty$.
  6. For large positive $x$, $\sqrt[4]{x^4-x^2}=x(1-1/x^2)^{1/4}$, which grows like $x$. Subtracting $x^2$ therefore tends to $-\infty$.

Sketch $f(x)=\dfrac{-3}{(x+1)^2}$.

Model answer · Question 8

QUESTION 096 POINTS

Find all values of $x$ where the piecewise function is not continuous: $f(x)=\begin{cases}3x-1,&x<-1,\\x^2+5x,&-1<x<1,\\3x^3,&x\ge1.\end{cases}$

Model answer · Question 9
At $x=-1$, the left and right limits both equal $-4$, but $f(-1)$ is undefined, so there is a removable discontinuity. At $x=1$, the left limit is $1+5=6$, while $f(1)=3$, so there is a jump discontinuity. The function is not continuous at $x=-1$ and $x=1$.

QUESTION 105 POINTS

Choose $A$ so that $f(x)=\begin{cases}1-3x,&x<4,\\Ax^2+2x-3,&x\ge4\end{cases}$ is continuous everywhere.

Model answer · Question 10
The left-hand value at $x=4$ is $1-12=-11$. The right-hand value is $16A+8-3=16A+5$. Set them equal: $16A+5=-11$, giving $A=-1$.

QUESTION 115 POINTS

Given $\lim_{x\to\infty}f(x)=7$ and $\lim_{x\to\infty}g(x)=-6$, find $\lim_{x\to\infty}\left(f(x)+\dfrac{g(x)}x\right)$.

Model answer · Question 11
By limit laws, $\lim f(x)=7$ and $\lim g(x)/x=(-6)/\infty=0$. Therefore the requested limit is $7+0=7$.

QUESTION 136 POINTS

Sketch $y=-4\cos\left(\dfrac{x}{2}+\dfrac{\pi}{2}\right)$ and show all key points.

Model answer · Question 13
Use $-\cos(u+\pi/2)=\sin u$: the function is $y=4\sin(x/2)$. Its amplitude is $4$ and period is $4\pi$. One cycle’s key points are $(0,0)$, $(\pi,4)$, $(2\pi,0)$, $(3\pi,-4)$, and $(4\pi,0)$; repeat every $4\pi$.
