== logic | 210 | Ch 1 | CH 01 | Logic and proofs
[grid]
[card Connectives]
[table]
p | q | p ∧ q | p ∨ q | p → q | p ↔ q
T | T | T | T | T | T
T | F | F | T | F | F
F | T | F | T | T | F
F | F | F | F | T | T
[/table]
!trap p → q is false **only** when p is true and q is false. Converse q → p and inverse ¬p → ¬q are not equivalent to it; the **contrapositive** ¬q → ¬p is.
[/card]
[card Key equivalences]
- p → q ≡ ¬p ∨ q
- De Morgan: ¬(p ∧ q) ≡ ¬p ∨ ¬q; ¬(p ∨ q) ≡ ¬p ∧ ¬q
- Distributive, absorption p ∨ (p ∧ q) ≡ p, double negation.
- Tautology: always true; contradiction: always false; contingency: neither.
[/card]
[card Quantifiers]
- ¬∀x P(x) ≡ ∃x ¬P(x); ¬∃x P(x) ≡ ∀x ¬P(x).
- Order matters: ∀x ∃y (x + y = 0) is true on integers; ∃y ∀x (x + y = 0) is false.
[/card]
[card Rules of inference]
Modus ponens (p, p → q ⊢ q) · modus tollens (¬q, p → q ⊢ ¬p) · hypothetical syllogism · disjunctive syllogism (p ∨ q, ¬p ⊢ q) · addition · simplification · conjunction · resolution.
[/card]
[card Proof methods]
- **Direct:** assume p, derive q.
- **Contraposition:** assume ¬q, derive ¬p.
- **Contradiction:** assume ¬(statement), reach a contradiction (√2 irrational).
- **Cases / counterexample** (one counterexample disproves a ∀ claim).
!tip "If n² is even then n is even": contrapositive: n odd = 2k+1 → n² = 4k²+4k+1 = 2(2k²+2k)+1, odd.
[/card]
[/grid]

== sets | 190 | Ch 2 | CH 02 | Sets, functions, sequences
[grid]
[card Sets]
- |A ∪ B| = |A| + |B| − |A ∩ B|.
- Power set: |P(A)| = 2^|A|. Cartesian product: |A × B| = |A|·|B|.
- A − B, complement, symmetric difference. Set identities mirror logic (De Morgan).
[/card]
[card Functions]
- **Injective (one-to-one):** f(a) = f(b) → a = b.
- **Surjective (onto):** every element of the codomain is hit.
- **Bijective:** both; only bijections have inverses.
- Floor ⌊x⌋ and ceiling ⌈x⌉: ⌊−2.5⌋ = −3, ⌈−2.5⌉ = −2.
[/card]
[card Sums]
- Σ i (1..n) = n(n+1)/2 · Σ i² = n(n+1)(2n+1)/6
- Geometric: Σ ar^k (k = 0..n) = a(r^(n+1) − 1)/(r − 1), r ≠ 1.
- Countable: ℕ, ℤ, ℚ; uncountable: ℝ (Cantor diagonal).
[/card]
[/grid]

== numbers | 150 | Ch 4 | CH 04 | Number theory and cryptography
[grid]
[card Divisibility and mod]
- a | b if b = ak. a mod m is the remainder in [0, m).
- a ≡ b (mod m) if m | (a − b). Add, subtract and multiply mod m freely.
- −7 mod 3 = 2 (not −1).
[/card]
[card GCD and Euclid]
[calc]
gcd(252, 198):
252 = 1 x 198 + 54
198 = 3 x 54  + 36
 54 = 1 x 36  + 18
 36 = 2 x 18  + 0     -> gcd = 18
lcm(a, b) = a b / gcd(a, b)
[/calc]
Bézout: gcd(a, b) = sa + tb (back-substitute). Inverse of a mod m exists iff gcd(a, m) = 1.
[/card]
[card Primes and Fermat]
- Every integer > 1 is a product of primes (fundamental theorem). Test divisors up to √n.
- Fermat's little theorem: a^(p−1) ≡ 1 (mod p) for prime p, p ∤ a.
- Fast power: square and multiply, reducing each step.
[/card]
[card RSA]
n = pq, φ = (p−1)(q−1), e coprime to φ, d = e⁻¹ mod φ. Encrypt C = M^e mod n, decrypt M = C^d mod n. Example p = 3, q = 11: n = 33, φ = 20, e = 3, d = 7.
[/card]
[/grid]

== induction | 205 | Ch 5 | CH 05 | Induction and recursion
[grid]
[card Mathematical induction template]
1. **Basis:** show P(1) (or the first value).
2. **Inductive hypothesis:** assume P(k).
3. **Inductive step:** show P(k) → P(k+1), using the hypothesis.
!tip For Σ formulas: write the sum to k+1 as (sum to k) + (k+1)th term, replace the sum to k with the formula, then simplify to the formula with k+1.
[/card]
[card Example]
[calc]
1 + 2 + ... + n = n(n+1)/2
basis n=1: 1 = 1(2)/2
step: k(k+1)/2 + (k+1) = (k+1)(k/2 + 1) = (k+1)(k+2)/2
[/calc]
[/card]
[card Strong induction and recursion]
- **Strong induction:** assume P(1)…P(k) to prove P(k+1) (prime factorization, postage problems).
- Recursive definitions: base case + rule (factorial, Fibonacci, strings, trees).
- Structural induction proves properties of recursively defined sets.
[/card]
[/grid]

== counting | 330 | Ch 6, 8 | CH 6, 8 | Counting and advanced counting
[grid]
[card Rules]
- **Product rule:** tasks in sequence multiply. **Sum rule:** disjoint choices add.
- **Inclusion-exclusion:** |A ∪ B ∪ C| = Σ|A| − Σ|A ∩ B| + |A ∩ B ∩ C|.
- **Pigeonhole:** N objects in k boxes → some box has ⌈N/k⌉.
[/card]
[card Permutations and combinations]
[table]
Order matters? | Repetition? | Formula
Yes | No | P(n, r) = n! / (n − r)!
No | No | C(n, r) = n! / (r!(n − r)!)
Yes | Yes | n^r
No | Yes | C(n + r − 1, r)
[/table]
Binomial theorem: (x + y)^n = Σ C(n, k) x^(n−k) y^k. Pascal: C(n, k) = C(n−1, k−1) + C(n−1, k).
[/card]
[card Recurrences]
- Linear homogeneous a_n = c₁a_(n−1) + c₂a_(n−2): characteristic equation r² − c₁r − c₂ = 0.
- Distinct roots r₁, r₂: a_n = α r₁^n + β r₂^n. Repeated root r: a_n = (α + βn) r^n.
- Use the initial conditions to find α, β.
[/card]
[card Worked recurrence]
[calc]
a_n = 5a_(n-1) - 6a_(n-2), a_0 = 1, a_1 = 4
r^2 - 5r + 6 = 0 -> r = 2, 3
a_n = A 2^n + B 3^n
a_0: A + B = 1     a_1: 2A + 3B = 4
B = 2, A = -1  ->  a_n = 2 * 3^n - 2^n
[/calc]
[/card]
[card Divide and conquer]
Master theorem: T(n) = aT(n/b) + cn^d. a < b^d → O(n^d); a = b^d → O(n^d log n); a > b^d → O(n^(log_b a)). Merge sort: a = 2, b = 2, d = 1 → n log n.
[/card]
[/grid]

== relations | 45 | Ch 9 | CH 09 | Relations
[grid]
[card Properties on a set A]
- **Reflexive:** (a, a) for every a.
- **Symmetric:** (a, b) → (b, a).
- **Antisymmetric:** (a, b) and (b, a) → a = b.
- **Transitive:** (a, b), (b, c) → (a, c).
!trap Symmetric and antisymmetric are not opposites: {(1,1)} is both; a relation can be neither.
[/card]
[card Special relations]
- **Equivalence:** reflexive, symmetric, transitive → partitions A into classes (congruence mod m).
- **Partial order:** reflexive, antisymmetric, transitive (≤, divides, ⊆). Hasse diagrams.
[/card]
[card Matrices and closures]
- Matrix: reflexive = all 1s on the diagonal; symmetric = M = Mᵀ.
- Composition = Boolean product. Transitive closure via Warshall's algorithm.
- Number of relations on an n-set: 2^(n²).
[/card]
[/grid]

== test | 340 | Self-test | TEST | Check your understanding
[qs]
? Practice :: Contrapositive of "if it rains, the ground is wet"?
= If the ground is not wet, it did not rain.

? Practice :: Negate ∀x ∃y P(x, y).
= ∃x ∀y ¬P(x, y)

? Practice :: Is (p → q) ∧ p → q a tautology?
= Yes (modus ponens)

? Practice :: |P(A)| for |A| = 5?
= 32

? Practice :: Is f(x) = x² from ℤ to ℤ one-to-one? Onto?
= Neither: f(2) = f(−2), and 3 is never reached.

? Practice :: gcd(84, 36)?
= 12

? Practice :: −11 mod 4?
= 1

? Practice :: Inverse of 3 mod 7?
= 5 (3 × 5 = 15 ≡ 1)

? Practice :: How many 4-letter strings from 26 letters with no repeats?
= P(26, 4) = 358,800

? Practice :: Ways to choose a 3-person committee from 10?
= C(10, 3) = 120

? Practice :: Integers 1–100 divisible by 2 or 5?
= 50 + 20 − 10 = 60

? Practice :: Minimum people to guarantee two share a birth month?
= 13

? Practice :: Solve a_n = 4a_(n−1) − 4a_(n−2).
= Repeated root 2: a_n = (α + βn) 2^n

? Practice :: Is "divides" on positive integers a partial order?
= Yes: reflexive, antisymmetric, transitive.

? Practice :: Coefficient of x²y³ in (x + y)⁵?
= C(5, 2) = 10

? Practice :: Master theorem for T(n) = 4T(n/2) + n.
= a = 4 > b^d = 2 → O(n²)
[/qs]
