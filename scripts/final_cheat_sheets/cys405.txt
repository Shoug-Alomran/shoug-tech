== intro | 210 | Ch 1 | CH 01 | Ethical hacking and pentesting
[grid]
[card Five phases of hacking]
1. **Reconnaissance** (footprinting): passive or active.
2. **Scanning:** live hosts, ports, services, vulnerabilities.
3. **Gaining access:** exploit.
4. **Maintaining access:** backdoors, rootkits.
5. **Clearing tracks:** logs, hiding files.
[/card]
[card Hacker types]
White hat (authorized), black hat (malicious), grey hat (in between), script kiddies, hacktivists, state-sponsored, insiders.
[/card]
[card Pentest types]
- **Black box:** no prior knowledge. **White box:** full knowledge. **Grey box:** partial.
- Rules of engagement and written **authorization** (scope) come first; the report comes last.
!trap Testing without written permission is illegal, whatever the intent.
[/card]
[/grid]

== recon | 190 | Ch 2–4 | CH 2–4 | Footprinting, scanning and enumeration
[grid]
[card Footprinting]
- **Passive:** no direct contact: search engines, Google dorks (`site:`, `filetype:`, `intitle:`), WHOIS, social media, job postings, Wayback Machine, Shodan.
- **Active:** touches the target: DNS zone transfer, traceroute, social engineering calls.
- DNS records: A, AAAA, MX (mail), NS, CNAME, PTR, TXT, SOA.
- Countermeasures: limit public info, WHOIS privacy, disable zone transfers.
[/card]
[card Scanning with nmap]
[table]
Flag | Scan | Note
-sS | TCP SYN (half-open, stealth) | SYN → SYN/ACK = open, RST = closed; never completes the handshake
-sT | TCP connect | Full handshake, logged
-sU | UDP | Slow; no reply may mean open
-sn | Ping sweep | Host discovery only
-sV / -O / -A | Version / OS / aggressive | Fingerprinting
-sX / -sF / -sN | Xmas / FIN / NULL | Closed port replies RST; no reply = open or filtered
[/table]
!trap Xmas sets FIN, PSH and URG. These inverse scans do not work against Windows (it always sends RST).
[/card]
[card Enumeration]
Extract users, shares, groups, services from open ports: NetBIOS (137–139), SMB (445), SNMP (161, community strings "public/private"), LDAP (389), NTP (123), SMTP (25: VRFY, EXPN), DNS (53). Tools: enum4linux, nbtstat, snmpwalk.
[/card]
[card Ports to know]
21 FTP · 22 SSH · 23 Telnet · 25 SMTP · 53 DNS · 80 HTTP · 110 POP3 · 143 IMAP · 161 SNMP · 389 LDAP · 443 HTTPS · 445 SMB · 3306 MySQL · 3389 RDP.
[/card]
[/grid]

== vuln | 150 | Ch 5–7 | CH 5–7 | Vulnerabilities, system hacking and malware
[grid]
[card Vulnerability analysis]
- Scanners: Nessus, OpenVAS, Nikto (web). Output: findings with CVE IDs and CVSS scores.
- Active vs passive assessment; credentialed vs non-credentialed scans; false positives must be verified.
[/card]
[card System hacking]
- Password attacks: dictionary, brute force, hybrid, rainbow tables (defeated by **salting**), password spraying, pass-the-hash.
- Tools: John the Ripper, Hashcat, Hydra (online), Mimikatz (Windows credentials).
- Privilege escalation (vertical / horizontal), keyloggers, spyware, steganography, **rootkits**, clearing logs.
[/card]
[card Malware]
- **Virus:** attaches to a host file, needs execution. **Worm:** self-replicates over networks. **Trojan:** disguised as legitimate (RAT = remote access Trojan).
- Ransomware, spyware, adware, rootkit, botnet, fileless malware, logic bomb.
- Analysis: **static** (inspect without running: strings, hashes) vs **dynamic** (run in a sandbox).
- Defence: antivirus/EDR, patching, least privilege, user training, backups.
[/card]
[/grid]

== web | 262 | Ch 8–9 | CH 8–9 | Web, database and social engineering
[grid]
[card Web attacks]
[table]
Attack | What happens | Countermeasure
SQL injection | Input changes the query: `' OR '1'='1' --` | Parameterized queries, input validation, least-privilege DB account
XSS (stored, reflected, DOM) | Attacker script runs in a victim's browser | Output encoding, CSP, HttpOnly cookies
CSRF | Victim's browser sends a forged request | Anti-CSRF tokens, SameSite cookies
Directory traversal | `../../etc/passwd` | Validate paths, chroot
Command injection | Shell commands through input | Avoid shell calls, whitelist input
Session hijacking | Steal or fix the session ID | HTTPS, regenerate IDs, timeouts
[/table]
Tools: Burp Suite (proxy, intruder, repeater), sqlmap, OWASP ZAP. OWASP Top 10 is the reference list.
[/card]
[card Social engineering]
Phishing, spear phishing, whaling, vishing, smishing, pretexting, baiting (USB), tailgating/piggybacking, shoulder surfing, dumpster diving, quid pro quo, impersonation. Tool: SET (Social-Engineer Toolkit). Defence: training, verification procedures, policies, MFA.
!hook Humans are the weakest link: every technical control can be bypassed by a convinced insider.
[/card]
[/grid]

== network | 205 | Ch 10–11 | CH 10–11 | Sniffing, DoS and wireless
[grid]
[card Sniffing]
- **Passive** (hub, monitoring) vs **active** (switched networks: MAC flooding, ARP spoofing).
- ARP poisoning → man-in-the-middle. MAC flooding overflows the CAM table so the switch acts like a hub. DHCP starvation and rogue DHCP. DNS poisoning.
- Tools: Wireshark, tcpdump, Ettercap, Bettercap.
- Defence: encryption (HTTPS, SSH), port security, dynamic ARP inspection, DHCP snooping, static ARP.
[/card]
[card DoS / DDoS]
- Volumetric (UDP flood, ICMP flood, amplification: DNS/NTP), protocol (**SYN flood**, Ping of Death, Smurf), application layer (HTTP flood, Slowloris).
- Botnets drive DDoS.
- Defence: rate limiting, SYN cookies, filtering, scrubbing services, CDNs, over-provisioning.
!trap Smurf = ICMP echo to a broadcast address with the victim's spoofed source; SYN flood = half-open connections fill the backlog.
[/card]
[card Wireless]
- Encryption: **WEP** (RC4, weak IVs, broken) → **WPA** (TKIP) → **WPA2** (AES-CCMP; KRACK) → **WPA3** (SAE).
- Attacks: evil twin / rogue AP, deauthentication, WPA handshake capture + offline cracking, WPS PIN brute force, jamming, bluejacking/bluesnarfing.
- Tools: Aircrack-ng suite (airmon-ng, airodump-ng, aireplay-ng), Kismet.
- Defence: WPA3/WPA2-Enterprise, strong passphrases, disable WPS, WIDS.
[/card]
[/grid]

== test | 340 | Self-test | TEST | Check your understanding
[qs]
? Practice :: Searching the target's job postings and WHOIS data is which phase and type?
= Reconnaissance, passive footprinting

? Practice :: Which nmap scan never completes the TCP handshake?
= -sS SYN (half-open) scan

? Practice :: In a SYN scan the target replies RST. The port is…
= Closed

? Practice :: Which flags does an Xmas scan set?
= FIN, PSH, URG

? Practice :: SNMP default community strings and port?
= "public" (read) / "private" (write), UDP 161

? Practice :: What defeats rainbow table attacks?
= Salting password hashes

? Practice :: Malware that spreads across the network by itself?
= A worm

? Practice :: Analyzing malware without executing it is…
= Static analysis

? Practice :: `' OR '1'='1' --` in a login field is which attack, and the main fix?
= SQL injection; parameterized (prepared) queries

? Practice :: A script stored in a forum post runs in every visitor's browser. Attack?
= Stored XSS

? Practice :: Following an employee through a badge door is…
= Tailgating (piggybacking)

? Practice :: Switch port flooded with fake MACs so it broadcasts all traffic. Attack?
= MAC flooding

? Practice :: Defence against ARP spoofing?
= Dynamic ARP inspection (or static ARP entries) and encryption

? Practice :: Flood of SYN packets that are never completed. Attack and defence?
= SYN flood; SYN cookies, rate limiting

? Practice :: Which Wi-Fi security uses RC4 with weak IVs?
= WEP

? Practice :: Fake access point with the same SSID as the real one?
= Evil twin

? Practice :: Black-box vs white-box pentest?
= Black box: no prior knowledge; white box: full knowledge of the target.
[/qs]
