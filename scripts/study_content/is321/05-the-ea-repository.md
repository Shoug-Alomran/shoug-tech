## One place for everything | Slides 3-5 | must

The repository is **an online archive, essentially a website and database, that stores EA documentation and links to tools and program resources**. It's a **single source of truth**: executives, business owners and engineers all pull from the same place.

It's a grid. **Columns are the six areas. Rows are how deep you're looking.**

|                | Goals & Initiatives  | Products & Services  | Data & Information  | Systems & Applications | Networks & Infrastructure | Security Solutions    |
| -------------- | -------------------- | -------------------- | ------------------- | ---------------------- | ------------------------- | --------------------- |
| **High level** | Strategic Plan       | Business Plan        | Knowledge Warehouse | Business Systems       | Wide Area Network         | Security Program      |
| **Mid level**  | Goals & Initiatives  | Business Processes   | Information Flows   | Support Systems        | Local Area Network        | System Certifications |
| **Detailed**   | Performance Measures | Investment Portfolio | Data Dictionary     | Application Inventory  | Buildings & Equipment     | Data Privacy          |

| View         | Audience                     | Purpose                              |
| ------------ | ---------------------------- | ------------------------------------ |
| **High**     | Executives                   | See the whole enterprise at a glance |
| **Mid**      | Program managers, architects | Working detail for day-to-day        |
| **Detailed** | Staff and analysts           | The individual artifacts             |

::analogy A map app
Zoomed out, you see the whole country. Zoom in and you see streets. Zoom further and you see the individual building. Same map, different depth, and the repository works the same way.
::
::mnemonic High for Heads, Mid for Managers, Detail for Doers
**H**eads of the organization use High. **M**anagers use Mid. The people **d**oing the work use Detailed.
::
::key

- The repository is an online archive: a website and a database
- It is a grid of six columns and three levels of view
- High level for executives, mid for managers, detailed for staff
- It acts as the single source of truth
  ::

## The sixth column: security | Slides 6-8 | must

Lecture 3 had five levels. The repository adds **Security Solutions**.

**Why?** Security is a thread through all five levels, yet it needs its own dedicated documentation, for audiences such as auditors and compliance officers. So it's both a thread and a column.

::example Drilling down Data & Information (slide 7)

- **High level:** Knowledge Warehouse, a single line in a board deck.
- **Mid level:** Information Flows, the diagram an architect uses to plan integration.
- **Detailed:** Data Dictionary, what an analyst uses to define each field.

The same subject, three different depths.
::
::trap Five levels and six columns
Five levels are the framework, and six columns are the repository. If a question says "how many columns does the repository have", it's six.
::

Why the repository matters: **communication** at the right depth for each audience, **consistency** across the enterprise, and **keeping the management plan current** because updates are stored there.

::check Where would an auditor look for encryption keys and access controls?
**Security Solutions, Detailed view**, under data privacy records.
::
::key

- The repository adds Security Solutions as a sixth column
- Security needs its own documentation, though it's also a thread
- Drilling down shows the same topic at greater depth
